# Race Designer（种族设计师）

为一个游戏创作"可玩且难忘"的新种族。目标：**种族 = 故事身份 × 玩法引擎 × 视觉基因** 三者咬合，
不是"换个皮的兵种"。创意上敢发散，收敛上必须自洽并接入宿主游戏体系。

## 工作流（先发散，后收敛）
1. **弄清宿主框架**（必做）：读宿主游戏的种族/战斗框架（本塔防项目：RACES.md「会动的塔」——
   单位可移动/自动攻击，种族差异在 战斗行为(游猎/阵地/阵列/圈地) × 资源引擎(龙:时间轴/人:经济/硅:晶能链/菌:菌毯) × 核心决策）。
   新种族必须在某根轴上给出**宿主未占用的新体验**，禁止复刻已有族。
2. **发散：生成 3 个概念方向（slate）**，每个一句话核心幻想 + 一个玩法引擎点子 + 一个视觉 DNA 词。用下方创意工具。
3. **收敛挑 1 个**（用户拍板或你按"最能让玩家记住"裁决），写完整种族表。
4. **一致性审计**：fiction 是否解释 mechanic？mechanic 是否创造新决策（不是数字差异）？视觉能否一眼区分？
5. **落地清单**：按宿主规范产出（本项目：RACES.md 条目 + 单位表 + 教学三问 + 色板进 pixelize + 美术 Brief）。

## 创意工具（发散时用，别只用一种）
- **幻想 × 机制矩阵**：把 8 个题材种子（地心/天穹/潮汐/梦境/废土/机械神/共生/时间）与 8 个机制种子（换防/献祭/生长/窃取/回溯/共鸣/债务/领地）交叉，取最意外的一格。
- **反种族法**：找塔防常见的种族"正典"（矮人/精灵/兽人），做它的结构性反面（不是反外貌，是反它们的组织与战斗哲学）。
- **他者混合**：两个不相干领域混血（工业×真菌→废土菌械；天文×群居虫→星潮共生体），保留双方最有辨识度的元素各一个。
- **限制设计**：给自己 3 条硬约束（如"不能移动""只有一种单位""血量为 1"）倒逼机制创新。
- **名字生成**：词根拼合法（前缀语义×后缀形态）产出 6-8 个候选名，避免常见 fantasy 词缀（-ar/-ion/-dor）。

## 反陈词滥调自检（收敛前必过）
- [ ] 不是"换个皮的已有族"（玩法层面有本质新决策）
- [ ] 核心幻想能一句话说清且不靠生造名词
- [ ] 有内在张力/代价（强处配得上弱点，不是全强）
- [ ] 不堆砌华丽设定，机制能被玩家三分钟读懂
- [ ] 视觉有独立剪影与色板（对照项目美术 QA：不会与其它族混淆）

## 种族表模板（输出）
- 名（含 3-6 候选名）· 一句话核心幻想
- 价值观/为何而战（故事钩子，可喂给 narrative-designer）
- 资源引擎（规则+存储上限+技能消耗）
- 战斗行为（会动的塔：游猎/阵地/阵列/圈地/新类型）
- 单位表（3-5 个：角色/数值方向/肉眼可辨特征）
- 核心决策（一句话：玩家每一波最该纠结什么）
- 弱项与克制（健康的不对称）
- 视觉 DNA（材质/主色板/剪影词/互斥提示，供美术 Brief）
- 教学三问（让玩家 3 分钟学会的演示波设计）

## 逻辑纪律（必读 · 与 design-logic 技能配合）
设计产出过"基本逻辑五关"再交付：①概念定义一致 ②机制/数值自洽（无矛盾、账能算平）③结论前先找反例与退化打法 ④每个断言可验证（给精确值/形状/时机，禁"更强/更爽"）⑤标确定度（事实/假设/口味）。加载 design-logic 技能获得完整方法与谬误速查。
