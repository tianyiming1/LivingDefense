**龙人身份硬锁**：肢完整；**仅 1 对背翼**；鳞尾；**女体 XOR 龙头**（女：女人脸+女体禁龙吻；男：龙吻+壮体禁女体）。  
恶魔脸混搭女体 / 武器盔甲 / 矩形补丁 / **第二对翼或髋副翼** / 割裂挖贴 = FAIL。

**禁止分区挖贴**：不要对翼/角/躯干分别 clear+paste。体型差用整图重出。

一眼判别：壮(焰鳞/岩夯) ≠ 纤(霜棱/碧枝)；翼大看碧枝；角大看雷冠；女看霜棱/碧枝。

## 每一种的标准子目录

```

  SPECIES.md
```

归档 ID：`dragon/longren/{id}/candidates`

**门禁**：candidates → 美术 Agent 过审 → `approved/` → 用户终审 → `picks/` → ship。肢错乱/副翼 = FAIL 删除。
