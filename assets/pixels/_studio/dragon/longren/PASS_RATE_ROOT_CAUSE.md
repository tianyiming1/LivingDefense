# 女龙人通过率偏低 — 根因（2026-09-03）

## 结论（先看这个）

通过率低**主要不是「抽卡运气」**，而是三件事叠在一起：

1. **验收条件叠太多且互相打架**（美型 / 大胸 / 禁龙头 / 胸罩+战裙 / 战士感 / 禁丑尖刺甲 / 禁武器 / 肢翼完整）——模型一次很难全中。  
2. **正向锚丢失，且旧锚本身违规**  
   霜棱 002 曾被夸，但是**多尾** → 已否决为 `ref_REJECT_frost_002_multitail.png`，**禁止再当生成锚**（用它 i2i 会烙多尾）。
3. **「战士装」提示词容易滑向尖刺重甲丑脸**（你已否决的那张），或滑向比基尼无裙 —— 两个都 FAIL。

男焰鳞能留下 011/022，是因为约束更少（壮 + 龙吻 + 单对翼），女角约束大约是男的 2～3 倍。

## 证据：FAIL 都死在哪

| 死因（占比高→低） | 说明 |
|------------------|------|
| 全裸 / 鳞片糊胸无明确胸罩+裙 | 曾清空 frost/jade approved；连你夸过的 002 也因此删 picks |
| 有胸装无战裙（比基尼底） | jade 006/007 等 |
| 尖刺银甲 / 盔冠 / 凶恶丑脸 | 你否决的战狂风；prompt 写 warrior 易滑过去 |
| 持剑等武器 | 如 021 |
| 肢乱 / 髋翼 / 女体+龙头互斥 | 次要但稳定存在 |
| 剪影低 denoise | 曾整批橙紫块，已废弃 |

## 管线层面的具体问题

| 问题 | 现状 |
|------|------|
| 正向锚丢失 | 旧 002 已否决为 `ref_REJECT_frost_002_multitail`（**禁锚**）；`ref_frost_002_hero` 已下架；女角缺合法单尾轻甲 PASS 锚 |

| prompt 过载 | 正面长句 + `style_lock` 再拼一段；负向又堆丑甲/裸/武器/龙头……信号互相冲 |
| 「战士」语义 | SD 常理解成 *heavy fantasy plate*，不是「轻甲胸罩+短战裙」 |
| 过审比生成严 | 生成「差不多」→ 过审按硬条全杀 → 表现为通过率极低 |

## 不是根因（别误判）

- Comfy 没挂（能出图）  
- 单纯「张数不够」（已出很多，是结构问题）  
- 男壮候选本身（magma approved 仍有货）

## 纠正办法（按优先级）

1. **正向美型锚**：用 `_refs/ref_female_beauty_board_*`（或**新**单尾+轻甲 PASS），**禁止** `ref_REJECT_frost_002_multitail` / 旧 002 英雄图当 i2i 锚（多尾会烙进去）。denoise 宜中低；prompt **只强调**：漂亮脸体型 + 铠胸罩+战裙 + 空手 + **恰好 1 尾**。  
2. **负向只打前几名死因**：裸、无裙、尖刺重甲、持剑、龙头、髋翼、多尾 —— 少堆形容词。  
3. **两段式**：先出「美型+轻甲+单尾」PASS → 再换色出碧枝，不要每张从零文生。  
4. **过审分级**：肢翼/多尾/互斥 FATAL；服装可标「差一点」进 `candidates/near/` 再定向改，避免全删重来。
