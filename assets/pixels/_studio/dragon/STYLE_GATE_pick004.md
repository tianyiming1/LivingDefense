## 纪律总则

**除非明文例外，一律按本文件 + `ANATOMY.md` + 亚种 `SPECIES.md` 全条款执行。**  
旧稿/夸奖稿/参考图若违规（如多尾的 frost 002）= **否决参考**，不得再当生成锚。

## 共享 PASS（缺一不可）

1. **真像素可交付**：验收以 game 档为准；无软插画糊边当定稿。  
2. **材质**：锯齿晶体块鳞家族，非赛璐璐光滑鳞。  
3. **肢**：2 臂 2 腿；爪手爪脚可读。  
4. **翅**：**仅 1 对背翼**（肩胛），与臂分离。禁止髋副翼、第二对翼、翅粘臂。  
4b. **尾**：**默认恰好 1 条尾巴**；未明文允许多尾则禁双尾/三尾/碎裂多尾。  
5. **身份 + 互斥（最高）**：腹板 + 鳞尾 + 龙人可读；**女体 XOR 龙头，不可同框**。  
   - **女路径**：漂亮**人类女人脸**（禁龙吻/爬虫头）+ 沙漏 + **胸部最大档** + **性感轻甲**（胸装+裙/甲裙；可性感；禁全裸、禁纯情趣无甲感、禁尖刺丑甲）+ **着装丰富且亚种可区分**（禁止五人同一套模具只换色）+ 角/鳞/翅/**单尾**/爪可留。  
   - **龙头路径（男）**：**龙吻/爬虫头** + **强壮**男体（禁大胸/女体沙漏/女人脸）；简甲差异可有。  
6. **完整一体**：无挖贴割裂、无漂浮色块、无武器盔甲分流；**肢逻辑正确**（关节连贯、无乱肢）。  
7. **黑底全身**；3/4 或侧面。

## FAIL（出现即删）

- **女体 + 龙头同框**（互斥）  
- **女角无胸装 / 无裙**；纯情趣无甲感  
- **尖刺重甲丑脸战狂风**（尖刺肩甲、华丽银盔冠、巴洛克钢甲、凶恶丑脸）— 否决样 `_refs/ref_REJECT_spiky_ugly_armor.png`  
- **多尾**（未明文允许多尾时：双尾/三尾/假第二尾）  
- 双对翼 / 髋副翼 / 翅长手臂  
- 躯干割裂、分区挖贴残留矩形  
- **乱肢、缺肢、多肢、漂浮脚/手、关节错位**  
- 武器刃手、四足龙冒充龙人  
- 只换色无体型差（尤霜棱≠焰鳞）
