# 数值模型

> [!abstract] 千问摘要
> 数值骨架（BALANCE_MODEL v1）：T_kill 2.5-5s、DPS 对称 ±10%、极限检查 ≤3×；当前实现（config.gd）人族五单位、三敌兵、波次公式与 12 波矩阵；波 7 输出密度不足待 B 轮。

> [!info] 两层结构
> - **骨架层**：BALANCE_MODEL v1（公式与基准，设计推导起点）
> - **实现层**：`scripts/config.gd`（当前生效数值，单一来源，调平衡只改这里）
> - Owner：数值设计师；每张数值表交付附"极限策略重算"页

## 一、数值骨架（BALANCE_MODEL v1）

### 1. 伤害-时间模型
- 目标击杀时间：单体怪在防线有效暴露段 T_kill ∈ [2.5s, 5s]（无操作下限；有操作 ≤1.5×T_kill）
- 怪血曲线：HP(w) = HP0 × 1.10^(w−1)（骨架目标；**当前实现仍为 +16%/波线性**，见实现层）
- 基准 Grunt HP0 = 55
- 单族 DPS 需求：DPS_req(w) = Σ HP_i(w) / T_kill_i

### 2. 成本-绩效对称基准（防"选族=选强度"）
- 每投入 100 金币 → 基准 DPS = 90（η=0.9，人族步兵基准）
- 全种族面板 DPS_per_gold ∈ [0.81, 0.99]（±10%）
- 面板偏离必须由机制抵偿（范围/减速/穿透/拦截），交付表注明对应关系
- **极限检查（每族交付必做）**：最优 vs 最差策略每波净收益差 ≤ 3×；超出调奖励系数或面板，**禁止砍怪血量掩盖**

### 3. 经济模型
- 收入 I(w) = 击杀奖励 ΣKill + 清波奖励（40 + 6w）
- **不启用利息**：存钱-花钱张力由各族资源规则承担（人族进化树/硅基晶能/菌族菌毯/龙族孵化位），避免第二货币
- 进化费 = 基础造价 × 0.5 × 段数（**CO-007 后**；原 0.8）
- 出售返还 60%；开局 $300（**CO-005 后**）

### 3.5 单位战斗属性（占位基准）
- 人族步兵 HP0 = 200；目标生存 T_survive ≈ 15s；怪对单位 DPS0 ≈ 13/s
- 移速基准：步兵 45 / 火枪 55 / 晶壁 30 / 蘑菇 40 / 龙族 110（飞行）——**全部低于跑者 150**
- 死亡惩罚经济上限：单位造价 ≤ 同级怪总奖励 120%（防送死流刷钱）；损耗率目标 ≤ 每波投入 20%

### 4. 技能数值规范
- 主动技能单次效果 ≤ 当前波 DPS 需求 30%（8s 爆发 ≈ 2 座基准塔）
- CD ≥ 2 波；大招 CD = 3 波——技能是策略点不是无敌按钮

### 5. 波次成长（扩展目标）
- 每 10 波 BOSS：血量 = 该波普通怪总血量 × 1.6，奖励 = 单怪击杀奖励 × 20（M2 内容项）
- 新增敌类型（空军/分裂/护盾）归 M2

### 6. 数据口径（评审用）
- 每局记录：[种族, 波次, 漏怪数, 总收入, 总投入, 平均击杀时间, 技能释放波次]
- 平衡指标：种族过关率 45%-55%；无脑最优打法胜率 ≤ 60%
- 难度指标：教程关首通中位数局数 ≤ 3；普通关 ≤ 5
