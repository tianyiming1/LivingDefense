# 架构与技术栈（TECH_STACK v1.0 — 技术总监定稿）

> [!abstract] 千问摘要
> 技术选型 Godot 4.5（GDScript 主），Python 仅工具链禁入运行时；ADR-001..005 决策、性能预算（≤150 实体/16.6ms）；config.gd 数值单一来源，wave12_test.gd 平衡回归管线。

> [!info] 结论先行
> - **游戏本体：Godot 4.5（GDScript 主，热路径可加 C#）**——现有原型即此栈，M1/S1 已验证
> - **Python：只做工具链**（AI 概念出图 / 平衡仿真 / 数据分析 / 生成 JSON），**禁止进入游戏运行时**
> - 不换引擎：换引擎=重写，违反重构纪律（"先这么写后面再重构"=重写，禁止）

## 需求约束（硬性条件）
| 约束 | 值 |
| --- | --- |
| 类型 | 2D 俯视塔防；单位可移动、自动攻击、怪物反击 |
| 同屏规模 | 己方 ≤30 + 敌方 ≤60 + 投射物/粒子 ≤60 = ≤150 实体 |
| 玩法核心 | 移动拦截 + 双向战斗 + 科技进化 + 技能 CD + 四族差异化 |
| 发布 | Steam（Windows 为主） |
| 预算 | 业余 10h/周 单人团队；零引擎许可费 |
| 迭代 | 每日原型验证，热重载优先 |

## ADR 记录（约束→决策→原因→风险）
| ADR | 决策 | 原因 | 风险/备注 |
| --- | --- | --- | --- |
| ADR-001 | 引擎 = Godot 4.5 | CanvasItem 2D 批处理适配 ≤150 实体；热重载；Steam 导出零费用 | 生态比 Unity 小，但全脚本自绘不依赖商店资产 |
| ADR-002 | 语言 = GDScript 主，C# 可选 | 现有实现全 GDScript 且冒烟通过；迭代最快 | 极热路径（>1万次/帧运算）可降 C#/GDExtension，当前不需要 |
| ADR-003 | Python = 纯工具链（禁进运行时） | 平衡仿真/数据分析效率高；生成 JSON 配置 | 若贪快写进运行时→性能与打包双失败，**一票否决** |
| ADR-004 | 数据契约 = JSON 单向（Python 生成 → Godot JSON.parse） | 数值/波次表由数据侧产出，引擎只读 | 字段变更需变更单控制 |
| ADR-005 | i18n = Godot 内置翻译系统 | CO-002 中英双语 | — |

## 性能预算（超标即阻断，技术总监门禁项）
| 项 | 预算 |
| --- | --- |
| 帧时间 | ≤16.6ms（60fps） |
| 同屏实体 | ≤150（己方 30+敌方 60+投射物 60） |
| 绘制 | CanvasItem 自绘合并批（unit/_draw）；禁止每帧新建材质/纹理 |

| 粒子 | 单单位 ≤30 点/帧 |

> [!warning] 已知坑
> 不设 APPDATA 时 Godot 写默认 user://logs 失败会 signal 11 崩溃（日志显示旧残留）——必须带 APPDATA 运行。
