# 硅基生命族 · 硅晶脉族（完整规格 v1.0）

> 状态：设计规格（S4 门禁为第 4 族决定项，本规格为决定评估基准）；Owner：主设计师
> 主题（用户指令）：以硅基科技为主——晶体、能量流、连接、自组织、再生
> 塔防表现：**重装阵列 · 晶脉拓扑（链）· 蓄能爆发 · 结构性再生**

## 1. 一句话定位

以"晶脉拓扑 × 蓄能爆发 × 结构再生"为三角的重装阵列种族——
防线是一套从枢纽生长出来的活电网：**站得越久越强，链得越长越强**。

## 2. 塔防表现（四族不重叠，见 RACES.md 对比表）

| 维度 | 硅基 |
| --- | --- |
| 防线形态 | **链**（晶脉网络，从枢纽向外生长） |
| 机动性 | 全场最低（重装）；移动=策略（打断蓄能） |
| 拦截能力 | **晶壁实体拦截**（四族唯一硬挡） |
| 输出形状 | 蓄能爆发（瞬间高伤）+ 共振沿脉传导（面） |
| 死亡处置 | 晶壁**免费再生**（前排盾）；晶核/晶刺**永久损失**（后排要保护） |
| 肉眼可辨 | 发光主链、沿脉传导波、晶壁碎裂再凝 |

## 3. 资源机制（晶能经济）

- **晶能**：每波结束 +1 × 场上已连接单位数；**存储上限 4，溢出不累计**
- 技能消耗：共振脉冲 3 晶能 / 晶化凝固 2 晶能
- **晶脉连接增益**：主链（最长连续链）每 3 单位 = 1 段，伤害 +10%/段（上限 5 段 = +50%）
- **分支**（主链之外的单位）：不计增益、计晶能——分支的意义 = 覆盖第二路怪流
- **部署规则**：任何单位必须部署在已连接单位的邻格（含枢纽）；从已有处延伸，天然成连片结构
- **经济极限检查（S4 前交付）**：有效收益差受"晶能上限 4 + 技能 CD ≥ 2 波"封顶 → 满足 ≤3× 纪律
  （链长唯一直接收益是伤害增益；晶能差异只影响技能频率且被 CD 和上限压平）

### 拓扑决策（每波 1 个真实决策）
延长主链（伤害增益）vs 分支覆盖（第二路怪流）vs 存晶能等技能

## 4. 单位（3 种 + 1 枢纽）

- **晶脉枢纽**（基地结构，每局 1 个）：不可移动、不可摧毁；部署起点
- **硅晶核**：站定蓄能 3s → 满能强击（单发高伤，单体）；移动打断蓄能；死亡=永久损失（重购）
- **硅晶刺**：站定蓄能 2s → 满能（优先攻击空军/高血单体）；**对空**；死亡=永久损失
- **硅晶壁**：站定硬度 +50%（受击减伤）；体积 2 格宽（卡位强度高）；**被击碎 → 10s 原地再凝（免费再生）**；移动中硬度降为 0
- 移速基准（< 跑者 150）：晶壁 30 / 晶核 38 / 晶刺 42 / 枢纽 0
- HP 占位：晶壁 280（硬）/ 晶核 160 / 晶刺 150 / 枢纽 ∞

> 损耗管理分层：晶壁免费再生 → 挪位挡怪是低风险操作；晶核/晶刺死亡 = 真损失 → 保护后排是族内玩法。

## 5. 主动技能（CD ≥ 2 波；大招 CD = 3 波）

| 技能 | 消耗 | CD | 效果 | 释放窗口 |
| --- | --- | --- | --- | --- |
| 共振脉冲 | 3 晶能 | 3 波（大招） | 主链全范围持续伤害 6s | 怪群全在主链覆盖段时顶波 |
| 晶化凝固 | 2 晶能 | 2 波 | 1 个敌人冰冻 3s（**四族唯一硬控**） | 冻 BOSS / 冻跑者救场 |

## 6. 优缺点

**优点**：最硬（晶壁硬挡）；单点爆发最强（满能强击）；唯一硬控；拓扑上限高（+50% 主链增益）；前排免费再生（损耗 0）
**缺点**：移速全场最低（跑者无解）；蓄能空窗（速射波弱）；拓扑定后难改、链断连锁脆弱；后排损耗贵（晶核/晶刺）

## 8. 教学任务（3 个可度量）

1. 从枢纽连出主链 **3 段**（9 个连接单位）
2. 晶壁顶前**挡住一个 Tank 波**（拦截次数 ≥ 5 次统计）
3. 共振脉冲在主链上燃烧怪群（**波及单位数 ≥ 10** 的可见计数）

## 9. 数值骨架（面板对称 ±10% 纪律）

- 场上单位规模：约 8-12 个（链式受限，介于龙族 ≤4 和人族铺场之间）
- 满能强击 = 蓄能 3s → 等效 DPS 按 3s 周期摊入面板基准；爆发倍率另计节奏收益
- 损耗经济：晶核/晶刺造价 ≤ 同级怪总奖励 120%（防送死刷钱）；晶壁再生免费但拦截有受击上限
- 极限检查：最优（主链满 5 段 +50% 伤害）vs 最差（单点无链）——靠"晶能上限 + CD"压平，S4 前由数值设计师交付重算表

## 10. 验收标准（可验证行为）

- 第 3 波行为：玩家第一步 = 从枢纽延伸部署；第 3 波时主链 ≥ 3 单位、晶壁已站定在怪流前（与龙游猎/人卡位/菌铺毯两两不同）
- 蓄能可见：晶核满能发光、强击命中反馈；链断可见：中段死亡 → 主链分裂、增益回落
