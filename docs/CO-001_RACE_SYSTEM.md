# 变更单 CO-001：引入种族系统（多种族 × 兵种技能差异化）

> 状态：**已批准**（用户拍板 2026-09-01 会话，二轮修正后 4 族定稿）→ 生效版本 0.2，S1 开工中
> Owner：制作人（调度）+ 主设计师（规格）

## 1. 为什么变

- 需求来源：用户提出"参考魔兽争霸 RPG 塔防，设置多个种族，每个种族的兵种技能不一样"
- 现状：M1 原型为单种族单局（5 塔 / 3 敌 / 12 波 / 单图），无种族维度、无主动技能系统
- 变更本质：M2 内容方向从"堆地图/堆塔数"重定义为"种族系统"——
  同一核心循环（布防→开波→击杀/漏怪→升级）不变，内容层换成种族差异化

## 3. 影响范围

- config.gd：TOWERS / ENEMIES 全局表 → 按种族分表（RACE = { id, name, units[], skills[], resource_rule 参数 }）
- main.gd：建造/升级挂接 resource_rule（菌毯蔓延结算 / 晶能扣减 / 孵化位占用）；**新增双向战斗**（单位 HP/受伤/死亡/补员、怪物索敌攻击单位、单位体积卡位）；状态机不变
- hud.gd：技能栏（1-3 号键 + CD 显示）、选族界面、**单位血条/战损统计**
- 平衡与教程：每族 3 任务教学；克制矩阵驱动波次编排
- 里程碑影响：见第 4 节

## 4. 实施顺序（每步带验收，不达标不前走）

| 步骤 | 内容 | 验收标准 | 排期 |
| --- | --- | --- | --- |
| S1 | 人族落地：config 种族化重构 + 技能栏 UI + 科技进化树 | 12 波可通、技能可释放且 CD 正确、全流程无报错（headless 冒烟 + F5 试玩） | 2 周（2026-09-01：脚本落地完成——config 人族单位表/unit.gd 移动拦截双向战斗/enemy.gd 边走边打/hud 技能栏+战损；headless 冒烟 EXIT=0 无脚本错误；待 F5 试玩验收后正式闭合 S1） |
| S2 | 菌族落地：resource_rule 抽象（菌毯蔓延 + 孢子传染：场地实体规则）+ 蘑菇单位 4 种 | 菌毯/传染闭环、菌族 12 波可通、按 BALANCE_MODEL 极限检查通过 | 2 周 |
| S3 | 龙族原型（不同轴验证：飞行单位 / 龙息线形穿透 / 龙巢孵化时间轴） | 与 R1/R2 打法决策可区分（RACE_VISION 三支柱验证） | 2 周 |

若只做 2 族：S1+S2 共 4 周，M2 验收点前移。
