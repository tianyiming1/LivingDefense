## 0. 一句话定位

装备 = **本局 2～3 件「世界馈赠」**，用来制造谈资与短窗抉择；不是第二套科技树，也不是永久成长网。

乐趣对齐：`决策密度 × 可学技能 × 失误可归因`（`RACE_VISION`）。装备只加「拿不拿 / 换不换 / 赌不赌」的决策点，不替代建防、经济、技能时机。

## 1. 设计原则（硬约束）

| # | 原则 | 可验证写法 |
| --- | --- | --- |
| P1 | **每局持有上限 2～3 件** | HUD 显示槽位；第 4 件触发「替换抉择」（必须弃一件）或拒收 |
| P2 | **仅局内获得** | 来源限：随机事件（挖宝/机缘/抉择）、探索点、**完美清波**奖励；开局不发装备 |
| P3 | **局终清空** | `WIN` / `GAME_OVER` 清空背包；无存档、无图鉴解锁数值、无跨局合成 |
| P4 | **不另起玩法状态机** | 装备是事件/清波的**掉落载荷**；效果挂既有资源（金/命/补给/晶能/菌毯）或短窗修正 |
| P5 | **不破面板对称** | 禁止「全军永久 DPS +20%」类裸面板；强度用**条件触发 / 单次 / 单波**自抑 |
| P6 | **种族兼容可读** | 每件标明：全族通用 / 某族增益更强 / 某族弱化或冲突；禁止「只有某族才能捡」除非文案明确为族专属遗物 |
| P7 | **失误仍可归因** | 每件生效时必有状态句（如「焦油壶：末段减速生效」）；玩家能说清「因为有 X 才活/才死」 |

### 明确不做（本里程碑）

- 跨局装备库、打造、词缀洗练、套装 2+2、商城永久解锁
- 独立装备栏养成 UI、装备等级、经验
- 与单位「穿戴」绑定的复杂装备系统（本作为**阵营遗物 / 战场道具**，不是 RPG 人物装）

## 2. 与随机事件 / 补给的接口（一句）

**装备不自起总线**：只作为事件池「探索挖宝 / 机缘悟道 / 抉择型」与完美清波的掉落载荷写入 `event_bus` 奖励表；人族相关件只读写既有 **Supply** 库存或产速闸门，不新增第三货币，也不绕开补给进化门槛。

### 接口细则（实现方读）

| 触点 | 约定 |
| --- | --- |
| 事件奖励字段 | `reward_type=run_item` + `item_id`；与金/命/补给奖励互斥或二选一（由事件规格写死） |
| 挖宝 | 「好」→ 候选池抽 1；「空」→ 无；「怪」→ 刷小怪，可选事后掉低级件 |
| 清波 | 仅当本波 `leak==0` 时，低权重（建议 ≤15%）可掉「清波系」件；已满 3 件则改为小额金 |
| 补给 | 仅 `item_id` 白名单可改 `supply` / `farmer` 产速；其它件禁止碰补给 |
| 同屏 | 服从事件总线：同屏最多 1 进行中事件；装备获得弹层可并入事件结算条，勿另开模态地狱 |

## 3. 持有与替换规则

1. **槽位**：固定 3；开局 0。目标体验每局自然落到 **2～3**（靠掉率与替换摩擦，不强制塞满）。
2. **重复**：同 `item_id` 不可叠两份；抽到重复 → 自动换成「等价小奖」（+15 金或 +1 补给，人族）。
3. **替换抉择**：第 4 件出现时弹二选一：「弃旧留新」列出当前 3 件可点弃；可「拒收新件」（保留原 3）。
4. **时机**：效果默认**立即入账**；标「下一波生效」的件在下一次 `WAVING` 开始结算。
5. **可见**：HUD 一行图标 + 悬停名；事件状态句复述效果关键词。

## 4. 候选装备表（≥8）

强度口径（相对 `BALANCE_MODEL`）：

- **温和**：约等于半次技能窗口或一小波经济摆动，不改变通关阈值主因
- **锋利**：能救一波或毁掉一波经济，须条件触发 + 可替换
- **危险**：易与族机制叠乘破对称 → 后置或加硬顶

## 6. 掉率与节奏（纸面，供 EVT 表填写）

以 12 波标准局为目标曲线：

| 波段 | 期望持有件数 | 主要来源 |
| --- | --- | --- |
| 1–3 | 0～1 | 早挖宝 / 第一次抉择（可空） |
| 4–8 | 1～2 | 挖宝 + 完美清波 |
| 9–12 | 2～3 | 替换抉择出现；后期商人 |

- 单局装备获取次数期望 **≈ 3.5**（含拒收/重复兑换），稳定落在 2～3 持有
- 同名装备整局上限 1；同名事件掉落冷却服从事件总线「同名上限」
- **禁止**每波必掉；禁止商店永久刷新出全图鉴

## 7. 平衡门禁（交付前纸面检查）

1. **无裸 DPS 永久加**：首包三件均无直接加伤  
2. **叠乘硬顶**：减速合计 ≤40%；治疗每波 ≤1 次  
3. **人族补给**：首包不改 `FARMER_SUPPLY_*`；EQ-04 后置且与 ECO1 联调  
4. **技能预算**：EQ-05 的「CD−1 波」整局仅 1 次，避免技能从策略点变每波按钮  
5. **极限策略差**：持有最优 3 件 vs 0 件，通关率差目标 ≤15pt（后验；超则砍数值不砍槽位）  
6. **Autoplay**：无装备路径必须仍 ACCEPT；有装备为可选增强，不为通关门闩

## 10. 结论

局内轻量装备用 **3 槽 + 事件/清波掉落 + 局终清空** 提供成长谈资，首包 **赏金匣 / 焦油壶 / 急救绷带** 覆盖经济、跑者、损耗三条决策轴；族专属与高风险件后置，避免在补给与天气未稳时破四族对称。
