## 状态机（同一律）

```
        移动(飞)              攻击?
  idle ──────► fly ◄──────────── attack
    │            │                   │
    │  Shift走   └───────────────────┘
    └────────► walk
```

| 游戏状态 | 动画状态 | 禁止同真 |
| --- | --- | --- |
| 未移动、未开火 | `idle` | 禁止播 walk/fly 脚程 |
| 位移中（默认） | `fly` | 扇翅+恒定升力；**禁止**大幅蹦 Y；飞帧须同高度 |
| 位移中（Shift） | `walk` | 贴地梦步；禁止保持大浮空 |
| `start_attack` / 施睡眠 | `attack` | 咏唱三段；禁止同时播完整 walk/fly |
| 睡眠命中目标 | **VFX 叠层**（目标上） | 禁止用橙红龙息色 |
| 梦雾（成年） | **地面/环圈 VFX** | 禁止无睡眠窗常驻雾 |

**矛盾律**：`hover_idle` 浮空仅属 **idle**；**walk** 须降高度；**fly** 才保持升力（用户明文可飞可走）。飞帧之间禁止 dy 差造成假蹦跳。

## 美学总则（可验收）

1. **剪影优先**：96×108 下 idle/walk/attack 三帧缩略图仍能辨「幼 / 亚 / 青」体型差。  
2. **材质一致**：晶块鳞 + 冰蓝白 + 深紫膜；禁熔岩橙铺面。  
3. **运动性格**：轻、飘、幻——缓起缓落，忌火焰线「冲刺残影橙」。  
4. **反馈语义**（ART_GUIDE §1.4）：每种特效 ↔ 唯一事件；颜色角色固定：  
   - 普攻弹道/枪口：冰蓝 `#7EC8FF`  
   - 睡眠：淡紫 `#A78BFA` / `#C4B5FD`  
   - 梦雾减速：半透明靛 `#2A1848` α≤0.35  
5. **预算**：单单位粒子 ≤30/帧；技能爆发 ≤0.55s 后回静。  
6. **残影**：梦龙残影色应为冰紫（`#9B8CFF` α0.4），**不得**沿用火焰橙残影（现网硬编码缺口 → 实现项）。

## 分阶动画表

### A. 幼龙 `unit_14` · Dream Whelp · 技能「入梦」

| 剪辑 | 帧 | 动作描述（逻辑） | 时长/节拍 | 验收 |
| --- | --- | --- | --- | --- |
| idle_0/1 | 2 | 四肢轻点地或微浮 4–6px；头鳍轻颤；翅膜收合扇 1 次/呼吸；星尘 0–2 点 | 呼吸 ~0.5s/相 | 脚影缩小；不原地跑步 |
| walk_0..3 | 4 | **梦步**：身体水平滑移，腿交替幅度小；尾随摆；翅半展维持升力 | 循环 ~0.5s | 前进方向可读；无重踏 |
| attack_0 | 蓄力 | 头微仰、翅后收、口鼻聚冰蓝点 | 0–28% | 蓄力回拉可读 |
| attack_1 | 释放 | 口喷短弧光弹（朝目标）；头鳍前压 | 28–62% | 与 `start_shoot` 同步 |
| attack_2 | 收招 | 翅回位、身回悬 | 62–100% | 回 idle 无 T 姿 |

**技能 VFX「入梦」**（目标位，非自身帧）  
- 触发：睡眠成功施加瞬间  
- 形：淡紫月牙环 1 圈 + 3–5 星尘向上飘散  
- 色：`#C4B5FD` / `#7EC8FF`  
- 时：0.35–0.45s  
- 目标持续睡眠：头顶 **Zzz 三点** 或淡紫呼吸高光（程序即可）

## 逻辑五关自检

| 关 | 结论 |
| --- | --- |
| 定义 | idle/walk/attack/VFX 与游戏状态一一对应 |
| 自洽 | 雾⊂睡眠窗；浮空⊂idle；色板≠火焰 |
| 反例 | 4 梦龙紫爆刷屏→半径/时长封顶；残影橙→改色 |
| 可验证 | 帧数、时长、色值、目录名均可检查 |
| 确定度 | 引擎契约=**事实**；帧内容描述=**设计规格**；手感毫秒微调=**假设待试玩** |
