## 为什么变
用户反馈像初级原型（无 BGM、UI/美术业余），要求工作室拍板产品化方向；并要求**合规第一**与**市场调研**并入纪律。

## 总判（制作人）
- **发售：** C — 现在发售易扑街，须先过 **M2 产品门槛**；不赌大卖。
- **策略：** **混合** — 开源只借壳（UI/地形/可选 CC0 音），单位身份自研 + STYLE_GATE。
- **顺序：** 先听（W1）→ UI Theme（W2）→ 战场底（W3）→ 人族（W4）→ 龙人 approved（W5）→ 合片（W6）。
- **玩法/数值本轮冻结**（治腻/R-ENG2 另单，不挡 W1 听感地板）。

## 纪律（不可砍）
1. **合规第一** — `docs/ASSET_POLICY.md`；无 LICENSE/provenance / `commercial_ok≠true` 不得进正式包与商店截图。
2. **市场常设** — 每月扫竞品钩子；不追 Incremental/默认 Roguelike/联机抢发；商店文案须与实机一致。
3. 定价默认 **$9.99**；Coming Soon 后 wishlist **硬门槛 5k** 再定档（或书面接受保本档）。

## 市场附件（摘要·公开估算非承诺）
- 热门：Incremental / Roguelike / 地形塑造 TD；本品不跟风。
- 钩子方向：「四族不同战斗逻辑 / 经营+防线」；截图必须能证明。
- 现实目标：健康首作量级（约 2k–8k 份经验区间）；大卖非 KPI。
