# 变更单 CO-033：人族从大本营走出部署

- **状态**：实施中
- **日期**：2026-09-03
- **需求**：人族部署的兵都是从大本营走出来的

## 规格

| 项 | 冻结 |
| --- | --- |
| 范围 | 人族；其它族不变 |
| 走出 | 战斗单位 + 农民：在 HQ 生成，行军至落点 `home` |
| 例外 | **补给站**仍就地建成（建筑，非兵） |
| 行军中 | 不交战；到达后若在波中则进战斗；农民到达后再寻站 |
| 占位 | `_can_place` 按各单位 `home` 互斥（行军中仍占落点） |
| 速度 | `def.speed × 1.4`（略快于战斗走位，减少枯等） |

## 决策密度

- 波中补兵有「行军窗口」——落点空窗期可被突破，须预判走位时间。
