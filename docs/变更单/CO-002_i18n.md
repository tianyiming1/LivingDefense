# 变更单 CO-002：中英双语支持（i18n）

- 状态：已批准 → **已实施并验收通过**（本会话）
- 生效版本：S1 人族（当前原型）
- 需求来源：用户 —— "游戏要支持 英文和中文"

## 为什么变
- 目标玩家人群含中英双语玩家；Steam 发行（M5）要求本地化（M4 门禁项：本地化完成）。
- 现在文本硬编码英文（HUD/状态栏/单位名），后期再改 = 全量返工；架构期搭建成本最低。

## 影响范围
- 新增：translations/strings.csv（翻译表）、project.godot [internationalization] 注册
- 修改：config.gd（单位/敌人数据加 name_key）、hud.gd（按钮文本 tr() + refresh_texts()）、main.gd（显示文本 tr() + T 键语言切换）
- 不修改：数据/数值（Config 数值表结构不变，仅加显示键）

## 技术决策（ADR-005：Godot 内置翻译系统）
- 约束：零外部依赖、性能预算内、默认中文为主、可运行时切换
- 方案：`tr("key")` + CSV 双列（zh_CN/en），project.godot 注册；运行时 TranslationServer.set_locale + HUD 重建文本
- 风险：hud 文案分散 → refresh_texts() 集中管理；CSV 编码必须 UTF-8（无 BOM）

## 验收标准（可验证行为）
1. 默认启动显示中文
2. 游戏中按 T：中文 → 英文 → 中文 循环切换，HUD/状态栏/单位按钮/结算文案全部立即切换
3. 无控制台报错

## 批准
- Owner：发行线（社区与商店经理）提出需求；工程线（管线+玩法）实施；制作人批准
- 截止：本会话内完成并按上表验收
## 实施结果（工程线返档，文档与实现一致）

### 实际落地
- `translations/strings.csv`：双语表 46 键（单位/敌人名、HUD、技能、状态消息、结算文案）
- `project.godot [internationalization]`：`locale/fallback="zh_CN"`，注册 **`.translation`**（非 CSV！见下方踩坑）
- `config.gd`：`HUMAN_UNITS`/`ENEMIES` 每项增 `name_key`（显示键；数据字段 `name` 保留英文原名）
- `hud.gd`：全部可见文本 `tr()`；新增 `refresh_texts()`（语言切换后整体重刷）；记录 `_lives/_losses/_wave/_last_*` 以便重刷
- `main.gd`：全部状态消息/单位名/结算 `tr()`；`_unhandled_input` 增加 `KEY_T` → `_toggle_language()`（`TranslationServer.set_locale` + `hud.refresh_texts()` + 结算遮罩按当前语言重建 + 信息面板重查）；`_ready()` 强制 `set_locale("zh_CN")` 保证默认中文；游戏结束态仅放行 T 键
- 遗留：语言暂不记忆（重启回中文），后续做设置页时加存档

### 踩坑记录（后续维护必读）
1. **Godot CSV 翻译解析器不支持引号转义、不支持字段内 ASCII 逗号** → 所有 en 文案避开 ASCII 逗号（用 `.` `/` `|`），zh 用全角标点
2. **运行时从 CSV 路径加载翻译失败**（`Failed loading resource: res://translations/strings.csv`），但直接加载 import 生成的 `.translation` 成功 → 项目设置注册 `.translation` 文件
3. 改 CSV 后必须重跑 `godot --headless --import --path <proj>` 重新生成 `.translation`

### 验收证据（可复现）
- `tools/i18n_check.gd`：双语 tr() 取值正确（zh: 步兵/开始波次；en: Cleric/overlay_defeat 整句）
- `tools/key_toggle_test.gd`：加载 main.tscn → 注入 KEY_T → HUD 实测 `金钱：$200 → Money: $200 → 金钱：$200`，无 SCRIPT ERROR —— 验收标准 1/2/3 全过
- 9 个脚本 `--check-only` 全过；main.tscn 900 帧运行时冒烟无报错
