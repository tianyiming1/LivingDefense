# CO-042：编制对齐 · 科技≠军衔 · 怪物点选

## 为什么变
- 去掉火枪/迫击直购；人族编制：**步兵、弓箭手、箭塔、法师、牧师**（+后勤）。
- **科技**分支升级 → 相关 kind 全员强化；**军衔**只升单兵。
- 法师为**群体 AOE**；牧师可升军衔（祭司→主教）。
- 军衔按钮显示中文下一阶；怪物可点击看面板与技能。
- 去火枪后重排中后盘波次与箭塔耐久，匹配新编制节奏。

## 影响范围
- `scripts/config.gd` — 单位表、波次构成、怪攻/HP 成长、敌人技能键
- `scripts/human_tech.gd` — 分支 buff / 解锁
- `scripts/unit.gd` — 法师溅射弹道与索敌
- `scripts/main.gd` / `hud.gd` / `enemy.gd` — 点选与信息面板
- `translations/strings.csv`、`tests/s1_autoplay.gd`

## 验收
1. 商店：步兵/弓/农/站直购；箭塔/法师/牧师需对应科技 Lv1。
2. 升「箭术」后所有弓手立刻变强；单兵升军衔只变该单位；按钮为「升→队长 $xx」中文。
3. 法师攻击有群体溅射；牧师可升→祭司→主教。
4. 点敌人：底部面板显示 HP/攻击/赏金 + 技能条目；有选中环。
5. S1Autoplay：**ACCEPT**（2026-09-03，`logs/S1Autoplay_CO042m.log`，110/0；单次样本）
