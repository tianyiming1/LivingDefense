## A. 技能释放之后会发生什么（以成年梦龙「群梦」为样板）

### A0. 同一律（状态定义）

| 时刻 | 事实 |
| --- | --- |
| T0 | 成年梦龙 CD 就绪，普攻命中主目标 |
| T0+ | 半径 R=78 内 ≤N=5 敌进入 `sleep`（停步；独立于麻痹计时） |
| T0~Tsleep | 梦雾圈存在；圈内未入睡敌移速 −12%（软帽） |
| Tend | 睡眠结束：雾 0.2s 淡出；怪恢复路径进度；CD=7.5s 起算 |

禁止：群眠无反馈、友军无行为变化、雾常驻。

### A1. 敌方反应（可见 + 可验证）

| 对象 | 反应 | 时长/规则 |
| --- | --- | --- |
| 被睡怪 | 停步、攻击停、淡紫高光、头顶 Zzz | = sleep_duration（成年 2.2s） |
| 圈内未睡怪 | 减速，不强制睡 | 仅雾窗 |
| 醒后 | 无硬直追加；继续原路径（不重置进度） | — |
| Boss/精英 | **可睡**但优先占 N 名额；醒后不额外狂暴（防随机翻盘） | 假设：若手感软可加「Boss 睡抗 +30% 时长减免」待测 |
| 飞行敌 | 若在 R 内同样可睡（法术无对地限制） | 事实：现 sleep 通道不区分飞行 |

### A2. 友方单位反应（行为层 · 设计规格）

反应分三档，落地可渐进：

**L1 必做（视觉/音频，无 AI 改）**  
- 状态句一句归因：「群梦落下——怪流停了一拍。」  
- 友军身上短闪冰蓝边 0.15s（同屏可读「我们吃到窗口」）  
- SFX：`sleep_chime` + 远处轻哈欠层

**L2 应做（轻 AI 偏好，不改面板）**  
| 友军类型 | 群梦窗内行为 |
| --- | --- |
| 火焰幼/亚/成龙 | 索敌权重：睡眠中目标 ×1.35（优先清睡团） |
| 铁鳞 | 不追飞；对最近睡怪保持站桩输出 |
| 爆裂系 | **不**主动贴睡团自爆（防浪费）；优先醒着的高密团 |
| 龙人施法 | 咏唱不打断；下一发优先睡目标 |
| 人族步兵 | 继续卡位；不后撤 |
| 人族弓/法/塔 | 索敌：睡目标优先（易集火） |
| 牧师 | 不浪费奶在满血；窗口期奶前排 |
| 菌毯/毒菇 | 毯伤/毒 **继续跳**（睡≠无敌）——逻辑：睡眠只停移动与攻击 |
| 硅晶核/刺 | 蓄力不取消；醒前尽量打在睡团上 |
| 硅晶壁 | 不移位；顶在睡团前 |

**L3 可做（叙事彩蛋，每局最多 1 次）**  
- 同场有火焰成龙时：状态句「焰息趁梦缝灌进去。」  
- 同场有麻痹蘑菇时：状态句「菌毯嫌梦太短——又补了一针。」（不叠机制，只文案）

### A3. 其它梦龙阶的后果差

| 阶 | 释放后 | 友军反应强度 |
| --- | --- | --- |
| 幼龙入梦 | 单怪停；星尘少 | L1 only |
| 亚龙重梦 | 单怪长停 | L1 + 弓/龙索敌微偏 |
| 成年群梦 | 一片停 + 雾 | L1+L2（招牌窗） |

### A4. 反例

| 反例 | 处置 |
| --- | --- |
| 睡中怪免疫一切伤害 | **禁止**——塔防窗口会变成无意义 |
| 群眠触发全军自动大招 | 禁止；仅索敌权重 |
| 友军冲进雾里自己睡着 | 睡眠只打 `enemy` 组 |
| 文案说「永久沉睡」 | 禁止；必须可对应 2.2s |

## B. 世界地基（三件套）

> **以怪写史**：完整怪物表与章节出场见 **CO-048**（monster-designer）。  
> 下文保留三件套摘要；细节以怪为准。

- **世界前提**：活体防线不是墙，是**契约地形**——四族曾用不同方式「喂」过这条廊道，如今廊道反噬，锈潮从裂口涌出。  
- **玩家立场**：你不是天选，你是**当班守约人**——选哪一族，就暂时成为那一族的意志（人=编制官，菌=毯之念，硅=脉之核，龙=巢之血）。  
- **敌方逻辑**：锈潮要的不是毁灭，是**解除契约**——把活体防线拆回死土，好让更深处的东西醒过来（Rampart Maw 是裂口的牙，不是最终因）。

Hook 一句：**「路上走来的，都是名册里被划掉的一行。」**

## F. 暗线（多线并行 · flag 驱动）

暗线不单独关卡，靠**事件抉择 + 波次碑文**叠三层真相：

| Flag | 如何获得 | 揭示碎片 |
| --- | --- | --- |
| `ash_name` | 人局 `sacrifice_pact` 接受 ≥1 | 祭品名在旧盟约里出现过 |
| `spore_memory` | 菌局清波且毯覆盖 ≥阈值 | 锈潮士兵细胞里有孢痕——曾是「友」 |
| `vein_echo` | 硅局共振击杀精英 | 晶脉回放：人族签字时龙位是空的 |
| `shadow_heard` | 事件听龙影（Y） | 解锁龙菜单资格（CO-044） |
| `dream_touch` | 龙局使用成年群梦 ≥3 次或通关 | 「睡眠」是盟约里的赦免条款误译 |

**暗线汇合条件（可验证）**：任意 3 个 flag → 通关碑文改写为「半真理」版；全 5 个 → 「门锁」版。

关键暗线论点（阵营辩证）：  
- 人：秩序能续命，也会删名。  
- 菌：蔓延是记忆，也会吞掉边界。  
- 硅：记录诚实，但不宽恕。  
- 龙：稀少是忠诚，也是傲慢。  
- 锈潮：拆约是为了让被删的东西回来——**含玩家删掉的龙名**。
