# 变更单 CO-004：收紧守位 + 目标锁定（消除"塔乱跑"）

- 状态：已批准 → **已实施并验收通过**（本会话）
- 生效版本：S1 人族（当前原型）

## 为什么变
- 用户反馈："塔放上去自己到处乱动"。事实核查：行为属于 CO-001 拦截型设计（合法），但两处观感缺陷：
  1. 追击半径过大（MELEE_CHASE=130 / RANGED_CHASE=80），单位离开部署点很远主动迎敌；
  2. 索敌每帧全扫重选"走得最远的敌人"，目标在多个敌人间切换 → 单位左右横跳。
- 裁决：收紧守位（近战仅小幅顶怪、远程基本站桩）+ 目标锁定（修横跳）。

## 影响范围
- 修改：config.gd（MELEE_CHASE / RANGED_CHASE 两参数）、unit.gd（目标锁定逻辑）
- 不修改：战斗框架、波次、经济、进化链

## 数值决策（参数化，可再调）
- MELEE_CHASE: 130.0 → 30.0  （近战只在怪贴脸时小幅前顶保持接触）
- RANGED_CHASE: 80.0 → 15.0  （远程站桩，仅轻微追踪维持射程边缘输出）
- 目标锁定：锁定目标存活且距离 ≤ range + chase + 20（缓冲）→ 持续攻击不换人；否则重扫。
  理由：+20 缓冲防止距离在边界来回导致反复解锁换目标（微抖动）。

## 影响与代价（极限检查）
- 收益：部署观感≈"塔"（守位），无横跳；玩法仍保留"单位可被怪边走边打、阵亡永久损失"的防线循环。
- 代价：近战顶怪距离缩短 → 防线更依赖密集布阵 + 补员；单位更易被怪群突破（平衡上靠 12 波可玩性验收回归）。

## 验收标准（可验证行为）
1. 部署 3 步兵 + 1 火枪手，开波：单位基本守在部署点，仅在怪进入射程时小幅前移/射击
2. 单波内观察：单位不出现左右往返横跳
3. 12 波通关（原 F5 验收项）不回退：无 P0/P1 报错、技能 CD 正常

  * 追击判定基准从 range 改为 reach（近战 22+30=52 内才小幅顶怪；远程 175+15 站桩边缘追踪）——第一版基准错误导致怪在射程边缘也能引走单位（实测 122px），已修正
  * 目标锁定 `_locked`：锁定目标存活且距离 ≤ reach+chase+20 不换人（防逐帧重扫横跳）

## 追加裁决 CO-004B：近战拦截顶停（用户拍板，推荐项）

### 事实（12 波赛跑 v1 证据）
- 收紧后防线失效：怪沿走廊中线走，边行边打（攻击不停留），合法布点距中线 >= 46px（走廊半宽 34 + 单位半径 12）→ 步兵索敌 65 / 追击判定 52 / 近战接触 22 全部够不到中线怪 → 怪全漏，第 3 波 lives 12→0 崩盘。
- 数值错位表：怪攻击 130px  vs  步兵索敌 65px vs 追击判定 52px —— 怪打得到兵，兵永远够不到怪。

### 机制（用户裁决：怪被近战顶住时停下交战——WC3 拦截 TD 正解）
- enemy.gd：近战单位接触怪 → 怪停下交战（攻击照常、不移动）；近战死亡/脱离 → 恢复行进。滞回防抖：停 28 / 保持 34。
- 近战=卡位肉盾（顶停+接触输出），远程=站桩集火（175 射程覆盖走廊）。
- 布阵结论：合法布点不只是"顶点外"，走廊线段外侧贴边（距线段 ~26px）可触发顶停——阵型知识写入关卡文档。
