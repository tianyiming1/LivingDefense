# 变更单 CO-039：飞行敌 + 自动拦截

- **状态**：已实施
- **日期**：2026-09-03
- **问题**：缺飞行怪课；近战可误打空中；出兵抵达后偶发未进入交战
- **方案**：
  1. 新敌 **飞翼斥候**（id7，`flying: true`）——近战/农民不可选为目标；弓/枪/迫击/弩/法师等远程可打
  2. 飞行敌掠过走廊，不受近战阻挡
  3. 第 5 波起混入飞翼；拉长近战拦截距离；HQ 出兵抵达后若已开波则自动开战
