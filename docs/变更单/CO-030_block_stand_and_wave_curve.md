# 变更单 CO-030：拦截站住打 + 波次递进差异化

- **状态**：已实施
- **日期**：2026-09-03
- **对齐**：试玩反馈「精英被兵推着走 / 太简单 / 每波应更难且不一样」

## 问题

1. **推着走**：`enemy` 被近战拦截后仍 `move_toward(单位)`；单位若在路径前方，精英等于被「领」着往前冲。
2. **过松 + 同构**：旧公式按波线性加同类怪，主题感弱；HP 成长偏软。

## 修复

| 项 | 做法 |
| --- | --- |
| 拦截 | 被战斗单位挡住时**站住交战**，禁止朝单位/路点前冲 |
| 农民 | 不再充当路径阻挡（避免误拦） |
| 精英质量 | 分离推挤对精英/Boss 大幅减弱 |
| 波次 | `wave_composition` 改为 **1～12 显式主题表**，每波构成不同且总压递进 |
| 成长 | 敌 HP 斜率 0.12→**0.14**；精英/Boss 面板略抬 |

## 玩家新决策

- 近战必须站稳砍，不能指望「把怪推走」
- 每波读构成/词缀/精英课，不能同一套摆法打全程

## 验收

S1 ACCEPT；推着走现象消失；波与波构成可读差异。
