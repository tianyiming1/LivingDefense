# 变更单草稿 CO-021：局内轻量装备（run items）

- **状态**：草稿（WP-EQ-D 产出；**未批准、未实施**）
- **日期**：2026-09-03
- **规格源**：`docs/装备_局内轻量_v1.md`
- **依赖**：事件总线可跑（WP-EVT1 / 预计 CO-019 事件池）；建议补给收紧（ECO1）先于 EQ-04
- **批准**：待用户拍板后再改代码

## 为什么变

试玩「玩一会儿就腻」：单图 + 决策稀。装备作为 **BL-30** 提供局内谈资与短窗抉择，且严格 **非跨局养成**，避免第二游戏。

## 冻结意图（实施时抄规格文）

1. 每局持有 **2～3** 件（硬顶 3 槽）；局终清空  
2. 来源：事件挖宝/机缘/抉择 + 完美清波；不自起独立状态机  
3. 首包只做：**EQ-01 清波赏金匣 / EQ-02 焦油壶 / EQ-03 急救绷带**  
4. 人族补给：首包**不改**产速公式；后勤账本（EQ-04）另单  

## 建议改动面（批准后）

| 区域 | 内容 |
| --- | --- |
| 数据 | `run_items` 表（id/名/效果脚本键/掉落标签） |
| 运行时 | `RunItemBag`：持有、替换、局终清空 |
| 事件 | `reward_type=run_item` 接入 event_bus |
| 清波 | `leak==0` 低权重掉 EQ-01 池 |
| HUD | 最多 3 图标 + 悬停；状态句 |
| 战斗（首包） | 末段移速乘区；单位低血触发一次治疗 |
| 测试 | 无装备 Autoplay 仍 ACCEPT；有装备冒烟不崩 |

## 不做

- 跨局图鉴数值、打造、套装  
- 首包族专属强装（碎晶/孢子/龙骨哨）  
- 赌徒骰子（EQ-08）首包  

## 验收（设计 → 工程）

- [ ] 一局能自然拿到 2～3 件  
- [ ] 第 4 件强制替换或拒收  
- [ ] 三件效果与状态句可读  
- [ ] S1–S4 无装备路径 ACCEPT  
- [ ] 减速硬顶 ≤40% 有单测或断言  

## 回滚

删除 `RunItemBag` 挂钩与 HUD；事件奖励回退为金/命；无存档字段则无迁移。
