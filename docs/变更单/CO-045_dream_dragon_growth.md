## 为什么变

彩蛋梦龙目前只有 **单阶**（`d_unit_14`，`evolves_to: -1`），与同族火焰/铁鳞/爆裂「幼龙→亚龙→成龙」时间轴不一致。  
玩家无法用孵化节奏养梦龙，控制位也停在幼体面板——补成长链，而不是再造新种族。

## 技能设计（机制先于数字）

控制语义（同一律）：`sleep` = 停步（与麻痹同类通道，独立计时器，淡紫视觉）——**已实现**。  
禁止：睡眠叠燃烧身份；禁止永久锁怪；禁止全场无 CD 群眠。

### 幼龙 · 技能「入梦」（单体）

- **被动普攻**：低伤法术弹（`kind: spell`）
- **触发技**：命中后若 CD 就绪 → **单体**睡眠  
- **玩家决策**：点杀跑者/精英窗口；对 Tank 价值低（血厚醒了还在）

### 亚龙 · 技能「重梦」（强化单体）

- **单体**睡眠时长↑、CD 略缩短（**不**做群体——群体留给成年）  
- **决策**：稳定点控高威胁单只，为进化成年攒节奏

### 成年（青年龙）· 技能「群梦 / 澄梦」（招牌：群体睡眠）

- **用户拍板**：成年梦龙可 **群体睡眠**  
- **规则（可验证）**：
  1. CD 就绪且普攻命中主目标 → 以主目标为圆心半径 `R` 内最多 `N` 个敌人同时进入睡眠  
  2. 群体睡眠时长 **短于** 幼/亚单体档（用覆盖换时长，防永久锁路）  
  3. 同目标多重睡眠 = `max(timer)`，不叠加延长  
  4. **附加梦雾**：群体睡眠窗内，圈内未睡到的敌人移速 −12%（软帽 `min(slow_total, 0.45)`）；睡眠结束 0.2s 消雾  
- **不**给伤害倍率；**不**替代族主动龙威  
- **决策**：怪团波一口气停一片，给火焰线清场窗；对单 BOSS 不如亚龙点控效率高（健康不对称）

### 族主动技关系

继续吃 `SKILL_DRAGON`（龙焰/龙威）——梦龙个体技不替代族主动。  
场上 ≤4 龙闸门不变。
