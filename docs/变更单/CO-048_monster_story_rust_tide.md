- **状态**：设计定稿（怪物表 = 剧情章；数值粗档，细调走 config）

## 0. 敌方势力一句话

**锈潮（The Unbound）**：被盟约删名后，用锈与空壳重组的「反编制」生物。  
生存理由：拆掉活体防线，好让被涂掉的名字从死土里站回来。  
材质基因：**锈铁皮肉 + 空名牌碎片 + 裂口黑雾**（废土×契约）。  
禁：龙鳞喷火、菌伞、硅六边、人族钢蓝——那些是守约方。

Hook：**「路上走来的，都是名册里被划掉的一行。」**

## 2. 现网怪「剧情化」怪物表（收敛版）

### 2.1 锈卒 · Grunt（id 0）

- **候选名**：锈卒 / 空壳兵 / 划痕人  
- **势力**：锈潮步兵层  
- **一句话威胁**：用数量把编制磨穿。  
- **ROLE**：grunt · 行为：列队推进、优先打最近单位  
- **外形**：敦厚矮胖剪影；锈皮肉；胸口一块**空白名牌**；锈红 `#BF4A2F`  
- **标志**：名牌无字（一眼）  
- **逼出决策**：开局买农还是买兵  
- **生存理由**：名被划掉后，身体只记得「向前走」  
- **叫声**：金属摩擦的短咳  
- **波次**：1+  
- **变体**：精英名牌闪一下残字（暗线 flag 可读）

### 2.2 缝影 · Runner（id 1）

- **候选名**：缝影 / 漏页 / 拆线者  
- **ROLE**：runner · 行为：绕打、冲终点  
- **外形**：修长侧棱；冰蓝灰；腿细如线  
- **标志**：身后拖一条「被拆的线」残影  
- **逼出决策**：要不要控速/卡位  
- **生存理由**：活着的意义是把盟约的缝拆开  
- **波次**：2+  
- **与他怪反应**：夜驿光环下变成「漏页潮」

### 2.3 铁壳 · Tank（id 2） / 铁皮 · Armored（id 3）

- **ROLE**：tank / armored  
- **外形**：敦厚堡垒；灰紫甲；铁皮多一层铆钉脸  
- **标志**：甲上嵌着**人族旧徽残片**（剧情：回炉友军装备）  
- **逼出决策**：换法师/溅射 vs 加步兵  
- **生存理由**：用守约者的铁，砸守约者的门  
- **波次**：坦克主题波 / 护甲教学波

### 2.4 掠空 · Sky Raider（id 7）

- **ROLE**：flyer  
- **外形**：尖三角翼；浅青灰；无腿或收腿  
- **标志**：翼膜是撕开的**契约纸页**  
- **逼出决策**：箭塔/远程是否到位（人弱空则痛）  
- **生存理由**：地上的约管不到天上的名  
- **波次**：CO-039 空袭波

### 2.5 攻城使 · Siege Herald（id 4）

- **ROLE**：siege/elite · 行为：慢推 + 护盾  
- **外形**：宽肩鼓盾；橙锈高光  
- **标志**：盾面刻「使」字残印（编制敌）  
- **逼出决策**：破盾集火还是放行清杂  
- **生存理由**：传令拆城——名册对面的军官  
- **波次**：命名精英波  
- **状态句**：「对面也有编制。」

### 2.6 夜驿 · Night Courier（id 5）

- **ROLE**：controller · 行为：光环加速周围锈潮  
- **外形**：修长斗篷；紫黑；手持空卷轴  
- **标志**：卷轴无字却发光  
- **逼出决策**：先杀驿使再清潮  
- **生存理由**：给被删的名字「续写速度」  
- **与梦龙**：群梦可停其周围潮，但驿使醒得快（假设：精英睡抗可后加）  
- **状态句**：「有人在给锈潮续写。」

### 2.7 廊牙 · Rampart Maw（id 6）

- **ROLE**：boss · 行为：盾 + 阶段甲  
- **外形**：横向巨口/牙床廊道；暗红；多层环  
- **标志**：牙缝里卡着四族色屑（人蓝/菌绿/硅青/龙金）  
- **逼出决策**：爆发窗 vs 持久磨  
- **生存理由**：它不是王，是**门锁**——咬住盟约不让重签  
- **通关揭示**：打掉牙 ≠ 填上名；碑文分叉  
- **叫声**：廊道回声的咀嚼

## 3. 新怪提案（支线 / 暗线 / 隐藏 · 尚未进 config）

每个先给剪影三连 → 收敛 1 个。

### 3.1 支线人族《编制册》——「涂名吏」

- **剪影三连**：①持笔瘦高 ②印章巨手 ③纸鹤群  
- **收敛**：① **涂名吏**（controller）  
- **威胁**：周期性使随机 1 个友军「暂时除名」——停止攻击 2s（非睡眠，灰名牌 VFX）  
- **材质**：墨+锈纸；禁紫梦色（不与梦龙抢）  
- **决策**：保输出位还是保前排  
- **波次**：人任务线第 2 关  
- **揭示**：删龙名的就是这类笔

### 3.2 支线菌族——「反毯孢」

- **剪影三连**：①倒伞 ②走毯虫 ③爆粉球  
- **收敛**：② **噬席虫**（runner+腐蚀）  
- **威胁**：踩过缩短菌毯半径一截（可恢复）  
- **决策**：毯密度 vs 追杀虫  
- **揭示**：锈潮记得被烧的席

### 3.3 支线硅族——「断链虱」

- **剪影三连**：①寄生钉 ②裂晶蛛 ③绝缘蛾  
- **收敛**：① **断链虱**（controller/寄生）  
- **威胁**：贴在硅单位上断开一段晶脉加成  
- **决策**：打虱还是保壁  
- **揭示**：晶回放里的「空签名」由它啃出缺口

### 3.4 支线龙族——「空巢影」

- **剪影三连**：①无翼四足虚影 ②假幼龙 ③吞孵口  
- **收敛**：② **伪巢幼**（grunt 诱饵）  
- **威胁**：外形像幼龙，打近才露锈核；吸龙威持续时间  
- **决策**：扫清诱饵还是保真龙进化  
- **揭示**：名册空页也会孵出假龙

### 3.5 暗线——「半名者」Pack-Name

- **ROLE**：elite/tank  
- **外形**：半边完整生物、半边锈空；名牌半个字可读  
- **威胁**：高血；死亡时按 flag 掉「真名碎片」状态句  
- **决策**：是否专打它换暗线进度  
- **组合**：与夜驿同波 = 加速的半真理

### 3.6 隐藏——「醒梦蛀」Dream-Wake Beetle

- **生态×角色**：梦境 × 反控制  
- **ROLE**：controller（克梦龙）  
- **外形**：圆钝甲虫；壳上裂开一只睁开的眼；色偏靛但**有锈边**（可与梦龙区分）  
- **威胁**：光环内睡眠时长 −40%；被睡时立刻挣扎缩短  
- **决策**：群梦前先杀蛀，或改火焰清场  
- **波次**：仅 `dream_touch` 后的隐藏波/事件  
- **揭示**：赦免被误译后，有东西专吃「睡眠条款」  
- **叫声**：牙齿磨眼睑的干响

## 5. 暗线 / 隐藏如何「用怪说完」

不写长篇：

1. 锈卒名牌偶尔闪残字 → `ash_name`  
2. 铁壳甲上人徽 → 人族罪证  
3. 噬席虫尸体掉孢痕 → `spore_memory`  
4. 断链虱死时晶鸣回放 → `vein_echo`  
5. 夜驿卷轴首次展开龙影剪影 → `shadow_heard`（接 CO-044）  
6. 醒梦蛀死后壳上「赦免」讹字 → `dream_touch`  

**剧情验收**：只看波次怪与一句状态句，玩家能复述「谁在拆约、门锁是谁、梦龙为何睡」。
