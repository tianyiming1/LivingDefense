# 变更单 CO-037：画面去遮挡 + 战场质感（压缩 HUD · 安全带 · 三件优先出图）

- **状态**：工程已接入；**2026-09-03 纪律复验**：`HUD_BOTTOM_PX=120`（dock y≥600）+ `tools/hud_fail_verify.gd` **VERIFY_ACCEPT**（同一律 + 南段路径 screen_y 不落底栏）
- **日期**：2026-09-03
- **Owner**：工程线（布局接入）/ 美术总监（资产迭代）
- **协作**：UI·UX（布局）· 概念美术（资产）· 工程线（坐标接入）
- **视口**：`Config.VIEW_SIZE` = **1280×720**（坐标均为相对此分辨率的像素）
- **前置**：继承 CO-034 的 Dota2 映射与右侧禁带；**废止** CO-034 §B 底栏高度（商店/英雄栏 144h）——本单以压缩高度为准
- **实现**：`hud.gd` 扁底坞；`map_fx.gd` 路径暖边+暗角；`hq.gd` y∈[70, VIEW_H−160]；镜头 `battle_camera` 用 `HUD_BOTTOM_PX` offset

## 为什么变

1. **用户反馈（事实）**：游戏画面有的被遮挡；画面太简陋，要重新设计。
2. **实测 HUD（`hud.gd`）**：商店 `(6,508,340,206)` 高约 206，盖住下半场；英雄栏 `(356,548,500,164)` 再叠一层；路径走廊与 HQ 出兵视线被底栏蚕食。
3. **CO-034 未闭环**：Dota 位正确，但底栏仍约 **144h**（从 y=568 起），安全带仍偏窄；地图仍以 `map.gd` 程序色块 / 粗线走廊为主，质感不足。
4. **硬目标（本版拍板）**：底栏常驻总高度 **≤120px**；商店可折叠或扁横条；英雄栏默认只留技能条；战场可视安全带内 **禁止常驻大块 UI**。

## 1. 遮挡诊断（当前 · 像素矩形）

坐标系：原点左上；矩形 = `(x, y, w, h)` → 覆盖区 `[x, x+w) × [y, y+h)`。

### 1.1 常驻 HUD 实测

| 区块 | 矩形 (x,y,w,h) | 覆盖像素区 | 对战场的影响 |
| --- | --- | --- | --- |
| 顶栏 | **(200, 4, 880, 48)** | x∈[200,1080], y∈[4,52] | 顶缘窄带，可接受；右缘 1080 已侵入 CO-034 禁带边缘 |
| 左下商店 | **(6, 508, 340, 206)** | x∈[6,346], y∈[508,714] | **主遮挡**：下半场左侧 ~21% 屏高被面板盖住；部署幽灵/走位单位不可见 |
| 底中英雄栏 | **(356, 548, 500, 164)** | x∈[356,856], y∈[548,712] | **次遮挡**：走廊中下段、贴路径站位被盖；与商店纵向重叠 y∈[548,712] |
| 右下操作 | **(880, 668, 200, 46)** | x∈[880,1080], y∈[668,714] | 底缘小簇，遮挡轻；宽 200 略超 CO-034 波次簇上限 |
| 科研浮层（HQ 选中） | **(400, 100, 400, 280)** | x∈[400,800], y∈[100,380] | **中场临时挡**；打开时挡中央走廊与选单位视线 |

### 1.2 底栏并集（常驻）

- 商店∪英雄栏∪操作 ≈ **x∈[6,1080], y∈[508,714]**
- **被挡战场高度**：从 y=508 到 720 → **212px**（约 29% 视口高）常驻不可见或不可点穿
- 与商店/英雄 **无水平重叠**（商店右缘 346、英雄左缘 356，缝 10px），但纵向叠成「整条底托盘」

### 1.3 玩法相关被挡区（结论）

| 玩法区 | 约略世界带 | 被谁挡 |
| --- | --- | --- |
| 下半场站位 / 贴廊部署 | y∈[508, 600+] × 全宽可用格 | 商店 + 英雄栏 |
| 左下路径弯（若 PATH 落入 y>500） | x∈[6,346] ∩ 走廊 | 商店整板 |
| 中下走廊接近段 | x∈[356,856], y∈[548,600+] | 英雄栏 |
| 中央选单位 / 走廊中段（仅科研开） | x∈[400,800], y∈[100,380] | 科研浮层 |
| 右缘 HQ 出兵口 | x≥1100（世界） | 当前商店已左移，**不再**被商店挡；仍须保持禁带 |

**诊断一句**：问题不是「没有 Dota 位」，而是 **底栏从 y=508 起过高（206/164）**，把可玩下半场吃掉；质感问题另见 §4。

## 2. 新布局冻结（Dota 灵感保留 · HUD 压缩）

### 2.1 硬约束（拍板）

1. **底栏常驻总高度 ≤ 120px**：所有常驻底区必须落在 **y ∈ [600, 720]**。
2. **战场可视安全带**（常驻大块 UI 禁入）：**y ∈ [70, 600]**，且继承 CO-034 **x ∈ [1100, 1280]** 右侧禁带（波次小簇除外）。
3. **商店**：默认 **扁横条 / 收起**；展开为临时抽屉（可侵入安全带，关闭后矩形不可点）。
4. **英雄栏**：默认 **只留技能条**；选中单位时信息/进化/出售为 **上浮详情**（临时），非选中时不得占满 164h 面板。
5. **科研**：仍仅 HQ 选中弹出；矩形不得与 HQ 命中盒相交；关闭后不可点。

## 3. 战场可视安全带

| 项 | 冻结值 |
| --- | --- |
| **安全带** | **y ∈ [70, 600]**（推荐；顶留 70、底留 120） |
| **底栏带** | **y ∈ [600, 720]**，常驻 UI 总高 ≤120 |
