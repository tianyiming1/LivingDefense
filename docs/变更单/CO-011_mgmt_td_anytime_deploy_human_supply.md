# 变更单 CO-011：经营+塔防核心循环 · 全程部署 · 人族补给/农民

- **状态**：实施中（M-H1+M-H2 代码已合入，待验收）
- **日期**：2026-09-03
- **生效版本**：config CO-011（START_SUPPLY / FARMER_* / HUMAN_UNITS id5 + supply_cost）
- **批准**：用户拍板
  - 玩法定位 = **经营 + 塔防**（非「波间布防小游戏」）
  - **全过程可部署**（全种族，非仅人族）
  - 人族专属：农民产**补给**（选项 1A）；农民**弱体积可挡路**（选项 2B）
  - 本阶段优先打磨人族；菌/龙/硅机制不加深，但须服从「全程部署」总规则

## 为什么变

1. **愿景对齐**：用户明确大纲——地图上隔一段时间来一波敌人；经营侧可持续生产；战斗侧随时可补单位。现行 `PLANNING` 才能建造，把经营感砍成「点开始前摆棋」，与定位不符。
2. **部署规则是全游戏规则，不是种族特权**：原先讨论稿曾写「仅人族随时部署」——**作废**。人族差异用农民/补给表达，不用部署门闩区分种族。
3. **人族身份补全**：在通用「经营+塔防」之上，人族用后勤线（农民→补给→高端兵闸门）形成「生产占位 vs 战斗占位」冲突；其它族后续各自经营钩子另开单，本单不加深。
4. **纪律**：设计变更须落变更单；禁止口头改循环。

## 冻结规格

### 1. 核心循环（全游戏）

```
地图固定路径
→ 敌人按波次间隔来袭（本阶段仍保留「点开始波次」按钮，不改为纯自动刷）
→ 任意时刻：建造 / 进化 / 出售 / 补员（有钱、有位、有补给门槛则校验）
→ 击杀与清波获得金币；漏怪扣命
→ 12 波通关或命尽失败
```

| 项 | 冻结 |
| --- | --- |
| 全程部署 | **是**（`WAVING` 与 `PLANNING` 均可部署；GAME_OVER/WIN 除外） |
| 点开始波次 | **保留**（本阶段不改为自动刷波；自动刷列为延后） |
| 适用种族 | **人 / 菌 / 龙 / 硅** 同一部署规则 |
| 卖点文案 | 仍兼容「塔会走、会流血、会进化」；经营侧用人族农民先落地示范 |

### 2. 人族专属：农民 + 补给（1A + 2B）

| 项 | 规格 |
| --- | --- |
| 单位 | 新增 **农民** 1 种（挖矿/种地仅文案/皮肤，机制合一） |
| 产出 | 独立库存 **补给（Supply）**；场上每名农民按间隔产出固定补给（数值入 `config`，禁止孤立拍数） |
| 上限 | 场上农民 ≤ **4** |
| 战斗 | **不主动攻击** |
| 挡路（2B） | **弱体积可挡路**（有碰撞/占位，可被怪打；非纯装饰） |
| 造价 | 仅金币；死后永久损失、可重购 |
| 放置 | 走廊外、互距规则同现有单位 |

#### 补给消耗闸门（推荐初值，实施时公式化后可调）

| 单位 | 金币 | 补给 |
| --- | --- | --- |
| 农民 | 有 | 0 |
| 步兵 | 有 | **0**（纯金币救急） |
| 火枪（建造或进化） | 有 | 少量 |
| 弩塔 | 有 | 少量 |
| 牧师 | 有 | 中量 |
| 迫击炮（进化） | 有 | 较多 |

原则：随时部署 ≠ 无限纠错；步兵可救急；高端线逼养农民。

### 3. 主动技能

- 人族 **Rally Fire 保留**（CD 波次制不变）。

### 4. 本阶段不做（砍/延后）

- 自动刷波作为默认节奏
- 食物/矿石双资源拆分、矿脉节点、耕地升级树、农民转职/开火
- 菌/龙/硅经营深度（菌毯/龙巢经济等另开单）
- 多地图、BOSS、新人族技能替换 Rally
- 利息系统

### 5. 与旧口径冲突（作废项）

| 旧口径 | 处置 |
| --- | --- |
| 「仅人族随时部署」 | **作废** → 全种族全程部署 |
| kb/02「避免第二货币」绝对表述 | **人族补给为例外**（技能向晶能仍不是建造货币；补给为人族建造/进化第二闸） |
| CO-011 计算草案里的全族 food/ore | 不整包落地；本单只做人族单一补给 |
