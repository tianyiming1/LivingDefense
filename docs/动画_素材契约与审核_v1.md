# 动画素材契约与审核规范 v1（ANIM CONTRACT & QA）

> 目标：**任何素材包必须在 Godot 里“丝滑动起来”，且“不过审的不能要”。**
> 本文件是生成端（Cursor/ComfyUI/AI）与引擎端（Godot）之间的唯一契约。两者都以此为准。

## 0. 铁律（结构强制，非口头纪律）

1. 每个动画帧包目录 `assets/pixels/{race}/unit_{id}_anim/` 必须含 **`REVIEW.json`**，且 `status == "approved"`，引擎才播放该包的帧（`UnitSprites.load_anim_frames` 与梦龙扇翅 Atlas 均先查此戳）。
2. `REVIEW.json` 只由 **审核工具**（PASS）或 **基线标记**（`baseline_v1`，仅限 2026-09-04 已入库的旧包）写入。**任何人/Agent 不得手写 approved**。
3. 新包不过审 = 引擎不认 = 游戏里不出现 = “不能要”由代码保证，不靠自觉。
4. 改帧后必须重跑审核；审核 FAIL 会覆写为 `rejected`，引擎随即停播该包。

## 1. 三种播放模式（引擎已实现，先选模式再开工）

| 模式 | 引擎消费方 | 适用 | 丝滑来源 | 素材要求 |
| --- | --- | --- | --- | --- |
| A 真分帧 | `unit_sprite_view.gd` `_pick_frame`（FPS: idle5/walk10/fly12） | 地面人形/兽形（走、攻击、死亡） | 帧数足 + 循环闭合 + 程序化 bob 叠加 | `{anim}_{N}.png` 序列（见 §2） |
| B Atlas 条带 | `_setup_dream_flap_atlas` `_apply_dream_flap`（FPS 8） | 飞行扇翅（梦龙 14-17 现状） | 相位独立 + region 切换，防“平移怪” | `fly_sheet.png` 等宽 cell 横排表（见 §2） |
| C 部件木偶 Path A | `_try_enable_puppet`（body/wing 部件 sin 旋转） | 占位/无真帧时的飞翼、悬浮 | 引擎程序化旋转，天然连续 | `unit_{id}_puppet/{body,wing_l,wing_r}.png` + `meta.json` |

> 判定顺序（引擎自动）：B/C 用不到时 → 走 A；A 缺/未过审 → 退回 base 静帧或 C。
> 新资产默认目标：**地面单位 = A，飞行单位 = B（有翅膀部件时可 C 兜底）**。

## 2. 真分帧 / 条带 硬性规格（逐条验收，全部满足才可能过审）

1. **画布**：同一包内所有帧宽高必须完全一致；新包一律 `96×108`（旧 64×72 兼容读取，但不作为新包标准）。`fly_sheet.png` 为整表横排，cell 宽 = 96（与引擎 `_flap_cw` 一致），行高 108。
2. **透明**：背景全透明，四角 alpha=0；无白底/黑底/网格残留。
3. **锚点**：地面动作帧的**脚底行必须保持在同一 y 行**（引擎按脚底定位，脚底上下漂 = 滑步/跳跃感，直接 FAIL）；角色居中于画布水平中线。
4. **命名**：`idle_N.png` `walk_N.png` `fly_N.png` `attack_N.png` `death_N.png`，N 从 0 连续，无跳号（引擎遇到断号即停）。
5. **帧数下限**：`idle ≥ 2`；`walk ≥ 4`（**推荐 6-8**：4 帧循环在落足帧接缝处易跳，8 帧才真丝滑）；飞行 `fly ≥ 4`（梦龙扇翅 ≥ 8 或整表 ≥ 8 cell）；`attack ≥ 3`（引擎按 3 段姿态取用：蓄力/挥击/收势）；`death 2-4`。
6. **禁止占位伪帧**：多个动作的帧不得是同一张图的复制（引擎有占位检测）；idle 帧之间不得完全相同（要有呼吸/明暗差）。
7. **循环闭合**：`walk`/`fly` 首帧与末帧剪影必须高度重合（首末剪影 IoU ≥ 0.65），否则循环播放最后一帧跳回第一帧时“pop”。
8. **色板**：主体颜色必须落在种族 PALETTES（`tools/gen/pixelize.py`）；离群色占比过高 = 未过像素化管线 = FAIL。
9. **锚点对齐产物**：全帧集齐后统一 `python tools/gen/import_ai_sprite.py --id {race}/{unit} --retro` 走管线；禁止把扩散直出图当帧直接入库。

## 3. 生成端流程（Cursor/Agent 每次动画任务必走）

1. 读本文件 + `.cursor/rules/art-direction.mdc` §四甲 + `docs/HUMANOID_PROMPT_LIB.md`（人形）。
2. 按 §1 选定模式 → 首帧定锚 → 帧间描述逐字锁定（只改姿势槽）→ 每帧 3-5 候选 → 与锚帧并排核对。
3. 帧落盘到 `assets/pixels/{race}/unit_{id}_anim/`（WIP 先在 `_studio/` 下同构目录，验收后拷入）。
4. **过审（强制性）**：
   ```bash
   python tools/gen/audit_anim_pack.py --race {race} --unit {id}
   ```
   PASS → 工具自动写 `REVIEW.json(status=approved)` → 可交付。
   FAIL → 按报告里的 `reasons` 返工，禁止“先入库再说”。
5. Godot F5/或 Autoplay 实际播放肉眼验收：无跳变、无滑步、无平移 → 交付。

## 4. 审核项（audit_anim_pack.py 逐项自动检测）

| 检测 | 口径 | 判定 |
| --- | --- | --- |
| 结构 | 命名连续/画布统一/透明背景 | FAIL：画布不一致、跳号、有底色 |
| 占位伪帧 | 跨动作帧像素近似度 | FAIL：idle≈walk≈base |
| 帧数下限 | 见 §2.5 | FAIL：缺失关键动作或单帧退化 |
| 锚点漂移 | 各帧脚底行（alpha 包围盒底）标准差 | FAIL >3px（walk）；>4px（fly） |
| 循环闭合 | 首末帧剪影 IoU | FAIL <0.35；警告 <0.65 |
| 色板合规 | 离群色像素占比（阈值 20%） | FAIL >20% |
| 静态残帧 | 同动作相邻帧完全相同 | FAIL（无动画可言） |
