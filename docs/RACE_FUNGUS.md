# 菌族 · 蘑菇菌落（完整规格 v1.0）

> 状态：设计规格（S2 落地基准：验证"场地实体/蔓延"规则抽象）；Owner：主设计师
> 主题（用户指令）：以各种蘑菇为主
> 塔防表现：**圈地菌毯（面）× 传染链 × 以死为输出**

## 1. 一句话定位

不打单点、打整条路的面积——先圈地，再让怪在菌毯上被慢慢磨死；
蘑菇被打爆也是输出（爆孢传染）——**怪越成群，菌族越强**。

## 2. 塔防表现（四族不重叠，见 RACES.md 对比表）

| 维度 | 菌族 |
| --- | --- |
| 防线形态 | **面**（菌毯覆盖路径地面；菌毯不移动） |
| 机动性 | 慢（蘑菇蠕动缓慢；菌毯=固定场地实体） |
| 拦截能力 | 无硬拦——菌毯减速 + 麻痹蘑菇定身（治跑者的唯一族） |
| 输出形状 | 地面 DOT（减速+持续伤）+ 孢子溅射 + **传染链** |
| 死亡处置 | 蘑菇死亡**爆孢传染** = 以死为输出；重购最便宜、补员最快 |
| 肉眼可辨 | 路径被菌毯染色蔓延；蘑菇群蠕动；怪群中孢子闪爆传染 |

## 3. 资源机制（菌毯 + 传染）

- **菌毯**（场地实体）：踩毯怪减速 25% + 持续伤害；染色可见
  - 自然蔓延：每波结束 +2 格（邻接已覆盖格）
  - 菌毯蘑菇：部署时立即在周围铺一片（局部加速）——**扩张决策**
- **孢子传染**：毒蘑菇攻击附感染标记；爆孢蘑菇周期喷孢（感染起点）
  - 被感染怪死亡 → 爆孢（传染半径 90）→ 相邻怪被感染 → **传染链**
  - 感染怪死亡时传染扩散计入菌族输出等效 DPS
- **部署规则（场地验证核心）**：蘑菇必须种在**菌毯上**（先铺毯、后种菇）——
  菌毯是地基：没有菌毯就没有防御，圈地先于布防（S2 验证 resource_rule 场地实体抽象）

### 核心决策（每波 1 个真实决策）
扩张 vs 强化（铺新毯/新菇 vs 升级菌落密度）；传染链发起位置（怪群中 vs 高价值怪）

## 4. 单位（4 种蘑菇）

| 单位 | 行为 | 移速 | HP（脆） |
| --- | --- | --- | --- |
| 毒蘑菇 | 攻击带毒（持续伤害 4s）+ 感染标记 | 40 | 120 |
| 爆孢蘑菇 | 周期喷孢子群（溅射 + 触发传染链） | 40 | 110 |
| 菌毯蘑菇 | 部署即铺一片菌毯（局部加速扩张） | 40 | 140 |
| 麻痹蘑菇 | 单体定身 2.5s（CD 3 波；对跑者/高价值怪） | 40 | 110 |

> 全部蘑菇移速同一档（蠕动）；菌毯本体不移动——机动性差异化在"菌毯扩张方向"而非单位走位。

## 5. 主动技能（CD ≥ 2 波；大招 CD = 3 波）

| 技能 | CD | 效果 | 释放窗口 |
| --- | --- | --- | --- |
| 菌毯沸腾 | 3 波（大招） | 菌毯伤害 ×3 持续 3s | 怪群全在菌毯上时顶波 |
| 孢子爆发 | 2 波 | 下波所有击杀额外爆 2 孢子 | 有感染链/高密集波前 |

## 6. 优缺点

**优点**：面积控制之王（减速+持续伤磨全路）；**克跑者**（减速+定身，四族唯一）；传染链（抱团群怪核武器）；以死为输出；造价最便宜补员最快
**缺点**：高血单体/BOSS 打不动（传染链对单体无效）；对空无力；开局真空（毯未铺开无输出）；蘑菇脆（损耗快，但死也输出）

## 7. 克制矩阵定位

| 敌人 | 菌族评价 |
| --- | --- |
| 空军 | **弱**（蘑菇对空无力） |
| 高速跑者 | **克**（菌毯减速 + 麻痹蘑菇定身） |
| 高血单体/BOSS | **弱**（传染链对单体无效） |
| 抱团群怪 | **克**（菌毯 + 传染链） |
| 开局 | 弱（先铺毯的真空期） |

## 8. 教学任务（3 个可度量）

1. 菌毯覆盖**主路径 50%**（覆盖格数 / 路径格数统计）
2. **引爆一次传染链**（单次感染扩散规模 ≥ 8 怪的可视计数）
3. 菌毯沸腾顶一波高密度（沸腾期间击杀 ≥ 15 怪）

## 9. 数值骨架（面板对称 ±10% 纪律）

- 场上单位规模：4 种蘑菇、造价最便宜 → 数量多（约 12-20 个，铺场型）
- 传染等效 DPS 计入面板；菌毯 DOT 按覆盖率折算（满覆盖 = 主链等效）
- 损耗经济：爆孢后重购（最便宜）；损耗率目标 ≤ 每波投入 20%（与通用规则一致）
- 极限检查：最优（满毯+传染链循环）vs 最差（开局无毯）——强度差由"蔓延节奏+教学任务"约束，S2 落地后数据校准

## 10. 验收标准（可验证行为）

- 第 3 波行为：先铺毯后种菇（菌毯覆盖 ≥ 路径 30%）；与龙游猎/人卡位/硅枢纽延伸两两不同
- 肉眼可辨：菌毯染色蔓延、蘑菇群蠕动、孢子闪爆传染扩散
- 场地规则验证：无菌毯区域无法种菇（resource_rule 抽象成立 = S2 门禁出口）
