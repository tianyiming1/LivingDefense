#### BL-01 规格（用户修正 2026-09-03）

**定位**：随机事件是「世界会出意外」的一层，**不是**唯一玩法，也**不是**只做 3 个。  
悟道 / 雷雨 / 挖宝 = **举例**；首包做总线 + 可扩展事件池，持续加条目。

**形态**：局内随时可能出现（波中/波间），非固定每 N 波菜单。

**事件池分类（可扩展，非闭环清单）**

| 类别 | 举例（可继续加） |
| --- | --- |
| 天气灾害 | 雨、雷劈（敌/己）、大风推怪、雾里射程缩短 |
| 机缘悟道 | 单位顿悟、技能提前就绪、短时进化折扣、种族共鸣 |
| 探索挖宝 | 宝点（好/空/怪）、遗迹、商人过路 |
| 危机压迫 | 提前跑者、补给被偷、终点震动、友军恐慌 |
| 战场变异 | 路径临时改道一小段、菌毯狂长、晶脉过载 |
| 抉择型 | 少数弹二选一（高风险高回报），作池内一类而非唯一 |

**工程约束**：事件总线 + 数据表驱动；同屏最多 1 个进行中；冷却与同名上限；必有状态句可归因。  
**首包 CO**：先落地总线 + 每类至少 1 条样例（证明可扩展），再按试玩加池。

**与「其它玩法」的关系（并列，不互斥）**

| 玩法支柱 | Backlog | 作用 |
| --- | --- | --- |
| 随时随机事件 | BL-01 | 惊喜与紧张 |
| 经营压力 | BL-02 | 每波仍要算账 |
| 多地图地形 | BL-10/11 | 站位课 / 空间技能 |
| 天气系统深化 | BL-20 | 可与事件联动，也可独立 |
| 轻量装备 | BL-30 | 局内成长谈资 |

| 美术音效 | BL-21/22 | 反馈与氛围 |

→ **好玩 = 多支柱叠加**；随机事件只是其中一根梁，禁止做成「整局只靠抽事件」。
