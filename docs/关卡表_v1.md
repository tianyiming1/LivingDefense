## 2. 撤退类型分布依据（为什么这么排）

| 关 | 为什么这关是这种类型 |
| --- | --- |
| 1 小镇 | 教程：教学关撤退无惩罚（NPC 带路撤），让玩家先懂"可以撤" |
| 2 山口 | 第一次真抉择：撤=触发分支；死守=可选（赢面小，教学"何时该撤"） |
| 3 渡口 | **必须死守**：民众正在过桥，撤=民众喂魔族 → 玩家学会"有些仗不能退" |
| 4 密林 | 伏击战：被包抄时你其实无处可"有序撤"→ 设计成可撤但撤=乱撤（减员更多） |
| 5 菌聚落 | 并肩关：撤=丢下盟友自己跑（道德抉择，flag 重） |
| 6 龙山崖 | 并肩关：可撤但崖道窄，撤=让盟友殿后（flag） |
| 7 硅遗迹 | **必须死守**：硅族把最后的晶能借给你守这廊道，没守住=全灭 |
| 8 大城外 | 可撤：正规军接应，压力在多段防线调度 |
| 9 决战 | 特例：死守大城=赢结局；主动再撤=放弃大城=开放式结局（非失败，是选择） |

## 5. 并肩关与结盟规则（用户拍板 v2：结盟 = 永久获得该族兵种）

**主线 = 人族守军一条线**（用户拍板 A 方案），但**结盟后队伍变成多族混编**：

- 关 5/6/7 遇到菌/龙/硅 = **相遇关 + 结盟机会关**（该族机制首次教学：并肩关可选该族单位）。
- **结盟成功（flag 达成）→ 该族兵种永久加入玩家的可部署池**：后续主线关卡都能用
  （人族 + 已结盟各族混编），随军/编成也含各族单位——队伍越撤越"杂"，越来越强。
- 结盟失败（对话选放弃/并肩关没守住）→ 该族线关闭：后续主线**用不了该族兵**，
  但有补偿不惩罚（如关 6 弃龙族得 `secret_pass` 秘道捷径，关 7 弃硅族得一次性护盾）。
- **为什么这样做**：叙事视角始终是"人族守军带着全镇人跑"，但战斗面是"一路收编的联军"——
  每结一盟，可部署池+1 族，玩家战术选择变多，撤退越到后期越有"攒家底"的成就感。
- **通关后**：开放**各族战役线**（菌/龙/硅各自独立战役线 = 更大内容盘子）——
  各族线展开完整机制深度（RACES 教学三问：铺毯/传染、孵化节奏、连脉/晶壁）。
- 平衡前提：各族面板 DPS/金币 对称 ±10%（BALANCE_MODEL）→ 混编 = 战术多样化而非数值碾压；
  队伍容量（兵民比例，跨关meta）限制总兵量 → 带哪族兵 = 每关的新决策。

### 5.1 编成规则（用户拍板 v3：种族闸 + 兵种线闸 + 槽=兵种线）
**防混乱双闸门**——限制"单关出战规模"，不限制"收集"。

- **种族闸**：每关出战种族 ≤ **2 个**（人族 + 1 个盟友族）。结盟全收（池子滚大），
  但每关只能选"人族 + 一个盟友族"上阵，不能三族四族混编——单关机制复杂度封顶。
- **兵种线闸**：每关**兵种线槽 = 4-5 格**，从所选 2 族的池子里选线。
- **槽 = 兵种线（不是具体兵种）**：科技树在线内纵向进化（步兵线→火枪→攻城车 = 同一槽），
  配兵槽管"带哪几条线"，科技树管"线内升到几段"，两者不冲突。
- 盟友族同理：结盟菌 → 菌族几条线（毒菇线/爆孢线…）入池，选线占槽。
- 结盟奖励 = 换着配：这关带菌、下关带龙、再下关带硅（每关配兵组合多），单关复杂度不涨。
- 渐进：前期人族 2-3 线起步 → 中后期最多 5 线封顶。
- 科技推进（主线内）：越靠近大城解锁越多条线/越高段位（接 CO-031/035/036/038 素材）。
