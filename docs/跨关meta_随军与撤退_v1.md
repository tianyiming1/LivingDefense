# 跨关 Meta v1：随军部队 / 兵民比例 / 撤退编成

> 状态：v1（2026-09 用户拍板）。衔接 CAMPAIGN §5.1（失利规则）与 关卡表_v1。
> 本文档定义"兵怎么跨关、撤退怎么挑人"——大撤退玩法的长线决策层。

---

## 1. 三条拍板（用户 2026-09）

1. **随军部队 = 跨关资产**。边防小镇开局有基础部队（不是空手起步）；
   前几关压力低、给足发展时间——因为后面的防守主力是**前面攒下来的兵**。
2. **队伍容量 = 兵 + 民，兵民比例玩家自定**（接"总人力 = 军队+平民"口径）。
3. **撤退 = 玩家挑选**：谁带走、谁留下断后换撤退时间（不是自动 −40%）。

---

## 2. 模型：队伍容量

```
队伍容量 C（占位值，数值 CO 定）
   ├─ 兵：战斗单位（每关可部署守关）
   └─ 民：跟随平民（占容量；漏怪时被扑的对象）
```

- 漏怪 = 敌人穿透防线 → 扑向平民 → 总人力下降（CAMPAIGN §5.1）；
- 平民归零 / 总人力归零 = 崩（本关重打，减员永久）。
- **容量是防止"无脑囤兵"的阀门**：兵塞满 → 没民 → 没血池/没劳动力；民塞满 → 守不住。

---

## 3. 撤退编成（可撤关 · 用户拍板流程）

1. 守不住 → 弹抉择「死守 / 撤退」（CAMPAIGN §5.1）；
2. 选撤退 → 进**编成界面**：列出当前随军全部单位；
   - 玩家把每个单位分到「带走」或「留下断后」；
   - 每个留下的单位 → 提供断后点数 D（单位越强 D 越高）；
3. 结算：
   - 断后点数 D → **拖住追兵**：民众多撤 X% / 下一关首波延迟 / 平民伤亡减少（按 D 结算）；
   - 带走单位 → 进下一关随军；
   - 留下单位 = 永久损失（写进 flag：谁为你断后）；
4. flag：`rear_guard_list`（断后名单）→ 结局叙事"被记住的人"。

> 决策张力：精兵留下断后换更多民众活命？还是把精兵带走保家底？
> 全留 = 等于死守（不给撤退时间）→ 界面禁止全留或等价于选死守。

## 4. 兵民权衡（为什么不能纯带兵）

| 民的功能（候选） | 说明 | 状态 |
| --- | --- | --- |
| A 劳动力 | 准备期修工事：民多 → 开局免费加固（墙体/减速带） | 待拍板 |
| B 道德/结局资产 | 带活的人 = 结局评分 + 叙事（多结局轴） | 待拍板 |
| C 血池 | 漏怪扣民：民多 = 容错高（漏几只没事） | 待拍板 |
| D 事件资源 | 某些事件/关卡需要民众完成（修桥/抬伤） | 待拍板 |
| E 收入 | 民劳作 → 每关 START_MONEY 加成 | 待拍板 |

> 纯兵流的问题：漏怪直接没缓冲 + 关卡目标（如渡口修桥）无人力 → 机制上逼你带民；
> 纯民流的问题：守不住。**兵民配比 = 每关开局前的战略决策。**

## 5. 招兵（后期也有，但前期铺垫更值钱）

- 每关可用本关金钱招新兵（补充随军，能带走，占容量——待拍板确认）；
- **前期铺垫的价值 = 进化度，不只是数量**：容量有限 → 前几关养出来的
  高阶/进化兵，比后期新招的白板强 → 前面花时间升级 = 后面有精兵可用；
- 敌人按随军战力缩放（占位公式，数值 CO）→ 屯再多白板也会被校准，精兵才是真优势。
