# 数值骨架（BALANCE MODEL v1 草案）

> 状态：公式骨架；占位参数待 R1 人族落地后按手感与数据校准
> Owner：数值设计师

## 1. 伤害-时间模型（一切 DPS 的起点）

- 目标击杀时间：单体怪在玩家防线有效暴露段内的击杀时间 T_kill ∈ [2.5s, 5s]
  （玩家无操作（只铺兵）的下限；有操作（技能/换防）后应 ≤ 1.5×T_kill）
- 怪血曲线：HP(w) = HP0 × 1.10^(w−1)，w = 波次
  （现行 +16% 线性成长改为每波 +10% 指数——线性成长在后期会消失压力感）
- 基础怪（Grunt 基准）：HP0 = 55（沿用现有值，作人族波次基准）
- 玩家单族 DPS 需求：DPS_req(w) = Σ_i HP_i(w) / T_kill_i（波内所有怪求和）

## 2. 成本-绩效对称基准（防"选族=选强度"）

- 基准：每投入 100 金币的单位，基准 DPS = 100 × η，η = 0.9（人族步兵基准）
- 所有种族、所有单位面板 DPS_per_gold 落在 [0.81, 0.99]（±10%）
- 面板偏离基准的部分必须由机制抵偿（范围/减速/穿透/拦截……），
  交付表须注明"面板偏移 ←→ 机制补偿"对应关系
- 极限检查（每族交付前必做）：最优策略 vs 最差策略的每波净收益差 ≤ 3×；
  超出即调奖励系数或单位面板，禁止靠砍怪血量掩盖

## 3. 经济模型

- 收入 I(w) = 击杀奖励 ΣKill + 清波奖励（40 + 6w，沿用）
  （利息机制不启用：存钱-花钱张力由各族资源规则承担——人族进化树/硅基晶能/菌族菌毯/龙族孵化位，避免第二货币）
- 进化费 = 基础造价 × 0.8 × 段数（人族段数 1、2）；升级费维持现公式 基础价 × 0.6 × 等级
- 出售返还 60%（沿用）；各族特殊资源规则挂 resource_rule（菌毯蔓延结算/晶能扣减/孵化位占用）
- 开局资金 $200（沿用）；测试期另设 $300 档用于手感对比（不发版）

## 3.5 单位战斗属性（占位参数，S1 按手感校准）

- 单位 HP0 基准（人族步兵）= 200；目标生存时间 T_survive ≈ 15s（被基准怪单体围殴）
- 怪对单位 DPS0 = 200 / 15 ≈ 13/s（Grunt 攻击占位）；随波次与 HP 曲线同斜率成长
- 单位移速基准：步兵 45 / 火枪 55 / 晶壁 30 / 蘑菇 40 / 龙族 110（飞行）——全部低于跑者 150（威胁与克制矩阵不变）
- 单位体积：步兵/蘑菇 1 格、晶壁 2 格（宽）→ 卡位强度差异（体积 × 硬度）
- 死亡惩罚经济上限：单位造价 ≤ 同级怪总奖励的 120%（防"送死流"刷钱）；损耗率目标 ≤ 每波投入的 20%

## 4. 技能数值规范

- 主动技能单次效果上限 ≈ 当前波 DPS 需求的 30%（8s 爆发 ≈ 2 座基准塔的输出）
- CD ≥ 2 波；大招（龙威/菌毯沸腾/晶化凝固）CD = 3 波
- 目的：技能是"策略点"不是"无敌按钮"；技能窗口波与非窗口波的手感差异必须可感知
  （玩家会主动规划"技能波"——这是 RACES.md 决策点清单的验证方式）

## 5. 波次成长与阵容（沿用 + 扩展）

- 阵容公式沿用 config.gd（坦克前置 / 刷兵主力 / 跑者压轴）
- 每 10 波 BOSS（新增）：BOSS 血量 = 该波普通怪总血量 × 1.6，奖励 = 单怪击杀奖励 × 20
- 新增敌类型（空军 / 分裂 / 护盾）归 M2，按克制矩阵决定它们在波次编排中的位置

## 6. 数据口径（交付评审用）

- 每局记录：[种族, 波次, 漏怪数, 总收入, 总投入, 平均击杀时间, 技能释放波次]
- 平衡指标：种族过关率目标 45%-55%（vs 模式启用后）；"无脑最优打法"胜率 ≤ 60%
- 难度指标：教程关首通中位数局数 ≤ 3；普通关 ≤ 5
