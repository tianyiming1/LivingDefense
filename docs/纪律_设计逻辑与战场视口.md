## 1. 逻辑五关（宣称前必过）

| 关 | 问什么 | 本项目落点 |
| --- | --- | --- |
| 定义（同一律） | 口径是否同一？ | `Config.VIEW_SIZE=(1280,720)` 为设计分辨率；`HUD_BOTTOM_PX` 为底栏高度；「16:9」只指该 VIEW，禁止与窗口拉伸观感混谈 |
| 自洽（矛盾律） | 两句宣称能否同真？ | 「底栏常驻盖住路径像素」与「玩家能看见并操作该段路径」**不得同真** |

## 2. 战场视口与底栏铁律

1. **比例**：`project.godot` 窗口基准 = `VIEW_SIZE`；`window/stretch/aspect` 必须为 **`keep`**（禁止 `ignore` 拉伸变形；`expand` 仅当 HUD 全锚点自适应且已测过越界）。
2. **安全带（PLAYFIELD）**：在 1280×720 设计坐标下，常驻可点大战场区为  
   **y ∈ [TOP_SAFE, VIEW_H - HUD_BOTTOM_PX]**  
   默认建议 **TOP_SAFE≈70**（顶栏+状态），底边 = `720 - HUD_BOTTOM_PX`。  
   **该带内禁止常驻**大块 `MOUSE_FILTER_STOP` 面板盖住路径。
3. **底栏**：常驻底栏高度 ≤ `Config.HUD_BOTTOM_PX`，全部落在 **y ≥ VIEW_H - HUD_BOTTOM_PX**。商店/科研列表用**临时弹层**（可关），不得把整表焊死在底栏里把高度顶进安全带。
4. **镜头**：若底栏与世界同视口叠加，则 `battle_camera` **必须**用 HUD 安全 offset + usable 半高，使默认/常用镜头下路径主走廊落在安全带内；改 `HUD_BOTTOM_PX` 必须同步改镜头。
5. **白屏/空画**：禁止用「未经验证的嵌套 SubViewport」冒充修比例；修显示问题先保主视口能画世界。

## 3. 验收（充足理由律——没证据=没修好）

至少满足其一，审核方可 PASS：

- [ ] 1280×720 截图：路径南段/关键折点未被常驻底栏遮死；或  
- [ ] 自动化：`tools/hud_fail_verify.gd`（或后继脚本）断言镜头可视矩形与 HQ/路径采样点关系；且  
- [ ] `Config.VIEW_SIZE` / `HUD_BOTTOM_PX` / `project.godot` 三处口径一致（同一律）。

命中任一逻辑谬误（偷换口径、事后归因、无证据宣称修好）→ **FAIL，禁止结单**。
