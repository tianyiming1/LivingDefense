> 口径：数值为【占位档】，细调走 config；波次归属随 §关卡表微调。

> 魔族 = 有组织的入侵军队，不是怪物潮——同场怪有"编制感"（有旗手/有军衔），是叙事也是玩法提示。

---

## 0. 编制观（怎么读这张表）

魔族是一支军队 → 玩家读场的方式 = 读敌方编制：
- **哪波来什么** = 敌方哪支部队压上来（grunt 炮灰开路 / runner 偷家 / tank 破阵…）；
- **同波组合** = 敌军配合作战（前 grunt 挡路 + 后 runner 偷家 = 逼你分兵）；
- **军衔怪**（精英/督军）= 这支部队的军官，出现即"这波要动脑子"的信号；
- 波表因此不是随机怪堆，是"敌军进攻计划"，玩家每次布防 = 读一次敌情。

## 1. 七角色位技能表（魔族版）

> 每怪四件套：一句话威胁 / 行为 / 技能（1-2 个，够用不堆）/ 逼出的玩家决策。

### R1 豺狼人 · Grunt（炮灰群 · 教学敌）
- **一句话威胁**：用数量把编制磨穿。
- **行为**：成群结队沿路推进，优先打最近单位；无技能，纯前排肉。
- **技能**：无（前 3 波教学期不给怪技能）；波次靠数量与 HP 成长加压。
- **逼出决策**：要不要铺兵挡第一口；铺多少（经济 vs 安全）。
- **变体**：豺狼人老兵（中后期）——死亡时嚎叫，给同波豺狼人 3s 攻速+25%（小型光环，逼你先清老兵）。

### R2 疾行魔犬 · Runner（快攻 · 偷家）
- **一句话威胁**：不跟你打，只想从你防线缝里钻过去。
- **行为**：四足快冲，绕过/穿过前排空隙，直奔队伍（终点）；打它的是路上任何能打到的单位。
- **技能**：① 冲刺（入场 1.5s 移速 ×1.6，不可减速低于某阈值）；② 成群时互相"垫脚"（跳过第一个挡路单位）。
- **逼出决策**：前排密度够不够；要不要减速/控制；布防是否留了纵深第二道。
- **波次升级**：后期成群魔犬 = "漏页潮"式压力（见 §3 组合）。

### R3 兽人重装 · Tank（破阵 · 前排克星）
- **一句话威胁**：你的前排在它面前是纸。
- **行为**：慢速压阵，高血高甲，优先顶着你最硬的单位打；被阻挡时原地挥击。
- **技能**：① 破阵锤——对阻挡它的第一个单位造成 ×1.5 伤害并击退半步；② 血性（HP<30% 攻速+40% 8s，濒死反扑）。
- **逼出决策**：近战磨还是换法师/溅射；是否留爆发技能给它。
- **教学位**：人族"铁皮/法师价值"课（对应旧 CO-012/038 教学点）。

### R4 蝙蝠怪 · 飞行（空军 · 绕防）
- **一句话威胁**：地上的防线管不到天上。
- **行为**：飞行路径越过地面单位，直扑队伍/后排输出点；只有对空单位/技能能打。
- **技能**：① 俯冲（锁定一个远程单位，1s 后俯冲造成伤害，可被对空火力打断）；② 超声（经过时使周围 1 个对空单位 2s 哑火）。
- **逼出决策**：对空单位/龙族是否到位；对空火力分散还是集中。
- **波次升级**：蝙蝠群 = 空袭波（对应旧 CO-039 空袭波）。

### R5 恶魔督军 · Elite/军官（精英 · 领导）
- **一句话威胁**：它在场，整支部队都更难打。
- **行为**：中速推进，高血；持盾（正面减伤 30%），每 N 秒挥一次范围顺劈。
- **技能**：① 督战光环——周围魔族攻速+20%（斩它则光环消失）；② 号令（每波限 1 次）——召唤一波小型豺狼人增援。
- **逼出决策**：先斩督军（破编制）还是先清杂（保阵线）；爆发技能留给它。
- **定位**：命名精英波的主力（对应 CO-024 机制课；出现="对面军官来了"信号）。

### R6 魔族术士 · Controller（辅助 · 藏在后排）
- **一句话威胁**：它不直接杀你，它让别的怪杀你。
- **行为**：停留在怪群中后部，不进近战；优先保命（会后退）。
- **技能**：① 嗜血术——给半径内 2 个 grunt/runner 攻速+50% 6s；② 疫病诅咒——使 1 个玩家单位被"腐蚀" 4s（受治疗减半，仅对牧师/奶类有意义）。
- **逼出决策**：先斩术士（限制强化）vs 先清前排（保命）；有没有能穿到后排的手段。
- **与 Runner 组合**：魔犬+术士 = "偷家加速潮"，必斩术士（对应 §3 组合）。

### R7 恶魔领主 · Boss（决战 · 阶段战）
- **一句话威胁**：它不是最后一个敌人，它是这支部队的意志。
- **行为**：Boss 关独有：阶段甲（按 HP 阈值切换行为）+ 召唤。
- **技能（阶段制，CO-028 结构沿用）**：
  - 阶段一（HP 100-66%）：重甲+顺劈，召唤豺狼人；
  - 阶段二（66-33%）：破阵锤+督战光环，召唤兽人重装；
  - 阶段三（33-0%）：狂暴（攻速+60%）+ 点名一个单位"处决"（高伤，可被控制打断）。
- **逼出决策**：爆发窗口（阶段切换时）vs 持久磨；控制链留给"处决"点名。
- **终局位置**：帝国大城决战第 18 波位（对应 CO-038 终局 Boss 位）。

## 3. 组合威胁（同波化学反应 · 关卡波表从这里拼）

| 组合 | 反应名 | 玩家决策 |
| --- | --- | --- |
| 豺狼人 + 疾行魔犬 | 「开路偷家」 | 前排挡 grunt 的同时留纵深拦 runner = 分兵 |

| 蝙蝠 + 术士 | 「空袭掩护」 | 先斩术士还是先上对空 |
| 魔犬 + 术士 | 「加速偷家」 | 必斩术士（否则 runner 太快） |
| 督军 + 任意 | 「军官带队」 | 斩首 or 硬抗光环 |
