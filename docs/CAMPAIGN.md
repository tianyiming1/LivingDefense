## 1. 世界观一句话

**帝国边境。魔族大军入侵。你是一座边防小镇的守军——最先被冲的人。**
守不住 → 上级命令往内地大城撤退 → 一路上魔族追兵不断 → 每张图是途中的一个临时阵地 →
路上遇到同样被战火卷入的各族聚落（菌/龙/硅）→ 合兵共守 → 越靠近帝国腹地，帝国大城的
先进科技支援越强 → 大城是最终目标。

> 世界观就长在玩法上，零造词：布防=扎营；开波=魔族来攻；漏怪=魔族扑进镇民队伍；
> 换图=撤退转移；兵随军=带着活口走；科技树=大城支援的装备。

## 2. 玩家身份与立场（拍板）

| 项 | 内容 |
| --- | --- |
| 你是谁 | 边防小镇守军（人族视角），不是天选者，不是将军 |
| 你带谁 | 全镇幸存者（队伍跟着你走；你守的是人，不是城堡） |
| 你往哪走 | 帝国内地的大城市（那里有更先进的科技/正规军） |
| 你的命令 | 上级下达撤退令；但撤到哪一步、怎么守，沿途由你决定 |

> 推论：玩家角色 = 普通人的担当。压力来自"身后的人"，不是"任务失败"。

## 5. 双引擎剧情（战况 × 对话 · 机制保留）

### 5.1 战况引擎与失利规则（用户拍板 v1：军队+平民总人力 · 撤/守抉择）
**总人力 = 你部署的军队 + 跟随的平民（百分比制）**——漏怪 = 民众伤亡，扣的是总人力；
军队战死和平民被害都从这里出账。这不是抽象"命"，是你手里所有活人的比例。

**每关两种结局出口（由关卡类型决定，见 §关卡表）**
1. **可撤退关**：守不住、伤亡太重 → 弹抉择「**撤退 / 死守**」——
   - 撤退：进**编成界面**——玩家挑谁带走、谁留下断后换撤退时间（不是自动 −40%，规则见
  `跨关meta_随军与撤退_v1.md` §3）；断后名单 → flag → 触发后续剧情分支；撤得早/晚、伤亡多少 → 不同 flag/剧情；
   - 死守：赌一把，守住了 = 惨胜（伤亡已重，叙事沉重），没守住 = 全灭 → 游戏结束。
2. **只能死守关**（叙事原因：民众正在身后过桥/撤了等于把民众喂给魔族）：无撤退选项——
   守不住 = 全灭 = **游戏结束**。

**全灭（游戏结束）处置（用户拍板）**：本关重打；**减员永久记录**（这关死的人不会复活，
写进存档/结局 flag），影响后续剧情与结局。
- 文案红线沿用：普通溃防称"转移/撤退"，**只有"只能死守关守不住"才出现真正的失败语义**（那是叙事认可的绝境）；
- **剧情全灭事件卡**（特定剧情节点，如断后掩护镇民过桥的必败战）：全军覆没 → 被下一阶段势力救起
  （救你的是帝国正规军/沿途聚落）——注意与"只能死守关"区分：那是叙事安排的牺牲，可预期、有后续；
- 连续伤亡 → 队伍越打越少、士气越低 → 镇民对话/选项变化（接对话引擎）。

> 兵民比例 = 队伍容量内的长线决策（`跨关meta_随军与撤退_v1.md` §2/§4）：边防小镇开局给基础部队、
> 前几关低压力供发展，后面的防守主力是前面攒下的兵——前期投入是跨关资产。
> 设计自检：死守选项必须"有时值得选"（如残兵太少撤了也没用 / 下一图敌人更强需兵力）——
> 否则死守 = 纯陷阱选项；每关在关卡表里写明"死守的赢面叙事"（守到援军/守到民众过完桥）。

### 5.2 对话引擎（flag 驱动 · 不设错误答案）
- 对话出现在撤退路上：镇民（老弱/民兵/伤兵）表态、各族首领交涉、上级命令的分歧；
- 每场 1-2 个选项，只立 flag 不开新剧情线（flag 决定：士气高低、各族好感、隐藏解锁、结局语气）；
- 示例 flag：`town_trust`（镇民信任）、`spore_alliance`/`dragon_pact`/`silicon_treaty`（各族结盟深浅）、
  `no_man_left`（是否总选殿后保人）；
- **没有错误答案**：每个选项都通向"继续撤退"，只是沿途的细节/结局语气不同。
- 战况（自动判定）定场景，对话（玩家主动）定方向，两者都写进 run flags / 存档。

## 6. 结局与隐藏（先占位，等主线走完再细化）

### 6.1 多结局（用户拍板：结局由"怎么玩"决定，非菜单选择）
- **原则**：结局 = 战况（守得好不好）× 对话 flag（结盟深浅/暗线发现）自然长出；
  无"坏结局惩罚"语气，每种结局都是故事的一种落点（延续"不打击"铁律）。

**结局轴 1 —— 到达大城时的状态（战况决定）**
| 状态 | 怎么打出来的 | 结局基调 |
| --- | --- | --- |
| 满编入城 | 一路顺风/从容转移 | 光荣收束：大城守住，镇民入城 |
| 残兵入城 | 多次提前撤退/牺牲多 | 代价收束：守住了，但碑文沉重——活下来的人记得谁没到 |
| 被救入城 | 触发过剧情全灭事件（断后掩护） | 救赎收束：你们倒下了，但有人替你们守到了城 |

**结局轴 2 —— 你沿途看见了什么（对话 flag 决定）**
| flag | 获得方式 | 结局改写 |
| --- | --- | --- |
| 结盟深浅（菌/龙/硅） | 并肩关是否救下聚落 | 大城决战有各族援军（满结盟=各族同守画面） |
| `town_trust` 士气 | 镇民对话选项 | 入城时镇民迎接的冷暖 |
| 魔族内幕暗线 | 暗线 flag 攒满 | 看清"魔族也是被逼的"→ 停战/求和的可能性出现 |

**结局候选（占位，主线细化后定稿，预计 4-6 个落点）**
1. 光荣入城（满编 + 全结盟）——"活体防线走到了城门口"；
2. 代价入城（残兵 + 结盟不全）——沉重但继续；
3. 中继（大城也只是撤退路上的一站，帝国还在退）——开放式，为续作留门；
4. 暗线真结局（魔族内幕 flag 满）——战争双方都有难民，停战或"看清没有赢家"；
5. 隐藏结局（第5族/隐藏内容解锁后，§6.2）——占位。

> 每个结局都是"同一段撤退史的不同讲法"：胜利者讲光荣，牺牲者讲代价，看破者讲真相。
> 不做"唯一正确结局"；通关后可选"重走"补 flag（二周目价值）。

### 6.2 隐藏内容
- **魔族内幕暗线**：魔族为什么打帝国？——留给后期反转（魔族也有被逼的/逃难的），
  由暗线 flag（如听到魔族内部对话的选项）累积解锁；**先不写死，防止变成"洗白反派"脸谱**。
- **隐藏第 5 族**：占位（用户此前要的隐藏种族）。候选定位 = 撤退路上遇到的"中立/被魔族毁灭
  的旧族遗民"，与四族决策轴不重叠（机动猎杀/阵型分工/拓扑硬度/面积传染已占）——
  设计时机待拍板（先占位不展开）。
- 龙族隐藏/梦龙等旧素材（CO-044/045/046/047）：其"睡眠/群梦"机制可作龙族特色保留，
  **叙事包装待重写**（旧"盟约条款/活证据"叙事作废）。

### 6.3 与旧草案的关系
- 余烬线 ≈ 逆风玩家"残兵继续走"的自然状态（并入战况引擎，不再单列）；

## 9. 时长目标与盘子换算（用户拍板：一次通关 ≥ 2 小时）

### 9.1 指标口径
- **目标**：玩家从序章打到决战通关，一次完整游玩（含合理失败重试）**最少 2 小时（120 分钟）**。
- 计量对象 = **主线单线**（人族守军视角，各族并肩关为主线一部分），**不乘四族**；
  （9 关逐关合计 ≈102 波，见 `关卡表_v1.md` §1，落在 90-100+ 目标区间）
  各族支线 / 隐藏内容 / 魔族暗线 = 通关后的追加时长（另计 1-2h+），不算进"2 小时通关"。

### 9.2 换算（占位假设，落地须实测校准）
| 项 | 假设 | 说明 |
| --- | --- | --- |
| 每波耗时 | 60-120s（战斗）+ 布防/规划 20-40s | 旧基线：12 波单局 10-15 分钟（M1 验证）≈ 1-1.3 分钟/波；RACE_VISION 30 分钟/局含决策 ≈ 2 分钟/波。**两口径待实测统一** |
| 图间剧情桥 | 60-90s / 图 | 撤退叙事 + 对话选项 |
| 失败重试 | 垫底 15-30% | 保证"最少 2 小时"不靠注水，靠重试天然达成 |

**盘子结论（主线示例）**：9 图 × 平均 10-12 波 ≈ **90-100 波**
→ 按 1.3-1.5 分钟/波 ≈ 120-150 分钟 ≈ **2-2.5 小时** ✓（含图间桥与重试，达标且不注水）。

> 与旧草案关系：旧"21 图 ≈300 波"是按"四族各自战役线"估的；现在主线单线 90-100 波即满足
> 2 小时，各族并肩/支线/隐藏另计。**盘子从"四族各一遍"改成"一条线 + 通关后内容"**。
