# 种族系统 · 愿景与设计原则（RACE VISION v0.3 — 4 族定稿）

> 状态：已批准（CO-001 于 2026-09-01 拍板，生效版本 0.2，S1 开工中）
> Owner：主设计师（本工作室）· 裁决：创意总监/用户

## 一、一句话愿景

一款把《魔兽争霸3》RPG 塔防的"种族构筑 × 防线布局 × 经济节奏"三重博弈做成独立游戏的塔防作品——
每个种族不是换皮，而是一套**完全不同的战斗逻辑**，玩家每局从选族开始就要做第一次设计。

## 二、三支柱（可验证）

| 支柱 | 定义 | 可验证行为描述 |
| --- | --- | --- |
| 核心体验 | 每波之间 1 个"钱怎么花"的真实决策；失误立刻可见 | 玩家在一局 30 分钟内做出 ≥30 次建造/升级/技能选择；每波结算时玩家能说清"刚才那笔钱花对/花错了" |
| 主题 | 多种族战场，种族=机制差异化，且体现在塔防表现上 | 选不同种族，前 5 波的建造序列、防线形态（线/点阵/链/面）、核心决策至少有两项明显不同 |
| 目标人群 | WC3 自定义图老玩家 + 轻策略竞技玩家 | 老玩家说出"这像 LTW/Element TD 的 X 机制并做了 Y 变化"；新玩家 10 分钟内学会一个种族 |

## 三、为什么 WC3 RPG 塔防好玩（行为级分析，非形容词）

基于 Element TD / Line Tower Wars / Wintermaul / Legion TD / Gem TD 的机制拆解，共通乐趣来源：

1. **回合级资金决策**：每波结束，钱只能花在一个互斥方向（存利息 / 升级 / 新单位 / 融合 / 发兵）。
   趣味 = 在"现在安全"与"未来更强"之间反复选择。——决策密度来源。
2. **一个可习得的技能**：
   - 融合配方（知识型，Element TD / Gem TD）
   - 迷宫路由（空间型，Wintermaul / LTW）
   - 发兵与升本节奏（节奏型，LTW / Legion TD）
   乐趣 = "我学会了并越来越懂"；这是重玩性的真正来源，不是难度。
3. **失误可见且代价明确**：漏怪/破口不是模糊的"输了"，而是防线可视地崩溃，且直接给对方送资源。
   玩家能归因："第 7 波我贪了 2 波利息"。→ 学习速度快，甩锅给运气的情况少。
4. **对手的不确定性（vs 模式）**：压力来自另一个人的针对性决策，而非纯脚本波次。多一层可读博弈。
5. **内容即谈资**：配方表、种族强弱争论、极限经济操作——这是自定义图长盛不衰的传播引擎。
6. **结算透明**：胜利/失败可归因到具体波次与资金决策。

> 反推设计结论：塔防"好玩"的引擎 = **决策密度 × 可学技能 × 失误归因**，三者缺一不可。
> 单纯堆伤害数字/堆波次数量不产生乐趣（无信息量难度）。

## 四、种族设计原则（本次立规矩，后续一切种族按此评审）

1. **种族 = 一套不同的核心决策 + 一套肉眼可辨的塔防形态**，不是换皮塔表。
   评审问题：这个种族"增加了什么决策""砍掉了什么复杂度"？并且它的**塔防形态**——建位规则 / 输出形状 / 防线角色（线、点阵、链、面）——必须与其它族肉眼可辨。答不出 = 不立项。
2. **资源/时间轴的差异比数值差异更"种族感"**：菌毯蔓延、晶脉拓扑、孵化位、科技进化树——资源形状不同，手感自然不同。
3. **技能 = 玩家主动释放的关键时机**：每个种族 2-3 个主动技能（CD ≥ 2 波），有明确的"什么时候放"的时机判断；被动差异并入机制。
4. **面板数值对称、机制差异化**：每族 DPS/金币 基准相同（±10%），强弱全部来自机制与克制——保证"选族=选玩法"而非"选强度"。
5. **每个种族有明确弱点**（克星/盲区），否则没有针对博弈，也没有双族配合的讨论空间。
6. **种族数量克制**：先 2 族（人族+菌族）验证系统抽象，再评估扩到 4 族（硅基为第 4 族决定项）。每个种族 = 一套系统 = 实现+平衡+教程三项成本。
7. **教程 = 种族任务线**：每个种族的专属机制用 3 个可度量任务教完（"让菌毯覆盖主路径 50%"），禁止"读说明书式"教学。

## 五、结论

- 方向：在现有 M1 原型上引入种族系统（选族→种族机制→主动技能栏），核心循环（布防→开波→击杀/漏怪→升级）不变。
- 该方向改动内容层（M2+），不动架构核心（状态机/建造/波次）。
