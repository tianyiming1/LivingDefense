# 关 1 · 边防小镇（教学 · 家）

- **场景**：你的小镇，熟悉的街道变成防线；远处魔族先锋的火光。
- **撤退类型**：可撤（教程版）——教学关，撤退由 NPC 触发、无惩罚，教"可以撤"。
- **玩法变体**：纯防守；单路 S 形（教学图）。
- **本关新决策课**：布防规则 / 开波节奏 / 经济（钱怎么花）/ 总人力概念（漏怪=民众伤亡）。
- **敌人**：只有豺狼人（无技能，教学干净）。

### 波表（8 波）
| w | 构成 | 要点 |
| --- | --- | --- |
| 1 | 豺×3 | 教你放第一个兵；漏一只看看总人力怎么掉 |
| 2 | 豺×4 | 经济：攒钱 or 铺兵 |
| 3 | 豺×5 | 第一只走到终点附近——教"拦在终点前" |
| 4 | 豺×6 | 双路小包夹（教学图简单分叉） |
| 5 | 豺×8 | 铺第二梯队；提醒纵深 |
| 6 | 豺×10 | 压力小高峰，检查前排够不够 |
| 7 | 豺×12 | 敌军"试探结束"，最密一波 |
| 8 | 豺×15 + 撤退令 | 撤到一半敌人停手（剧情）；NPC 带路撤退 |

- **死守赢面叙事**：不适用（教程可撤，撤=剧情主线）。
- **对话与 flag**：撤退前镇长对话——选项 A「能带多少带多少」（`no_man_left+`）/
  B「保兵要紧，平民随后」（`army_first+`）；教学关选项只立 flag 不改难度。
- **失败与重试**：漏太多总人力归零 = 重打本关（教学无永久减员记录，让玩家放心试）。

# 关 2 · 山口（第一道撤离线）

- **场景**：镇外山口，你们第一次主动选阵地的位置；能看见追兵烟尘。
- **撤退类型**：可撤——第一次真抉择。
- **玩法变体**：纯防守；单路+中段窄口（宽度只够 1-2 个前排，卡位价值体现）。
- **本关新决策课**：读 Runner（漏怪代价）/ 纵深第二道 / 何时该撤的判断。
- **敌人**：豺狼人 + **疾行魔犬（新）**。

| 4 | 犬×4 | 教减速/控制价值 |

- **死守赢面叙事**：死守 = "赌援军/赌敌人只是先头部队"——**死守赢面小**（教学：这时候该撤）；
  若死守成功 = 惨胜，敌军退去（奖励：多带 10% 民众），但剧情走"倔强守军"分支（flag `stubborn`）。
- **对话与 flag**：撤前军官对话——A「殿后掩护，民众先走」（`no_man_left+`）/
  B「一起走，别再死人」（`town_trust+`）。
- **失败与重试**：死守失败=全灭 → 本关重打，减员永久记录（这是第一次玩家真正体会减员）。

# 关 3 · 渡口（民众过桥 · 无路可退）

- **场景**：大河渡口，浮桥正在搭，几百镇民在岸边等；魔族追兵从林线压出。
- **撤退类型**：**只能死守**（民众过不完桥，撤=把他们喂魔族）。
- **玩法变体**：限时断后——守到浮桥搭好/民众过完 = 胜利（时间条可见）；守不住=全灭。
- **本关新决策课**：破甲（兽人出现）/ 换输出类型 / "有些仗不能退"。
- **敌人**：豺狼人 + 疾行魔犬 + **兽人重装（新）**。

- **死守赢面叙事**：时间条=希望——"守到桥好"是明确的、可见的赢面（不靠赌）。

- **失败与重试**：全灭 → 本关重打，减员永久（民众死伤记录进结局，桥头这场戏是"代价"的首次重锤）。

# 关 4 · 密林（遭遇战 · 被包抄）

- **场景**：撤退路线穿过密林，魔族一支偏师从侧翼包抄——你们被夹在林道里。
- **撤退类型**：可撤——但撤=乱撤（被包抄时没有有序退路，撤=更多减员）。
- **玩法变体**：遭遇战——敌人从两个方向来（正路+侧林道），阵型被迫分散。
- **本关新决策课**：对空（蝙蝠怪出现）/ 双线布防（资源分配）。
- **敌人**：豺狼人 + 疾行魔犬 + 兽人 + **蝙蝠怪（新）**。

| 3 | 豺×5+犬×2 | 正路压力 |

- **死守赢面叙事**：守到"敌军偏师被正面主力召回"（时间窗口）——死守=赌敌军是偏师；
  若守成 = 全歼偏师，缴获（少量科技点）。
- **对话与 flag**：遭遇时侦察兵报告——A「绕右侧林道突围」（`audacious`）/
  B「就地筑垒等主力撤完」（`cautious`）——决定本关出口方向/减员构成。
- **失败与重试**：可撤关；若选守失败=全灭 → 重打，减员永久。

# 关 5 · 菌族聚落（并肩 · 第一盟）

- **场景**：密林尽头，一片发光的菌落——菌族聚落正在被魔族围攻；你们赶到时它们在死守。
- **撤退类型**：可撤——但撤=丢下盟友自己跑（道德抉择，flag 重）。
- **玩法变体**：**并肩关**——菌族盟友与你共守，可部署菌族单位（解锁菌族用法）；
  菌毯蔓延形成第二层"活"地形。
- **本关新决策课**：盟友系统 / 菌族机制（菌毯/蘑菇/传染）/ "救不救"的道德成本。
- **敌人**：豺狼人 + **豺狼人老兵（新）** + 兽人 + 蝙蝠。

- **失败与重试**：若撤=丢盟友（flag 已记）；若死守失败=全灭 → 重打，减员永久。

# 关 6 · 龙族山崖（并肩 · 空中走廊）

# 关 7 · 硅族遗迹（并肩 · 最后掩体）

- **场景**：古战场遗迹，硅族把最后的晶能借给你们守这条窄廊——廊后是开阔平原，无险可守；
  守不住，后面的人全暴露给魔族。
- **撤退类型**：**只能死守**（廊后无掩体，撤=集体暴露=全灭）。
- **玩法变体**：并肩 + **窄廊地形**——晶脉链沿廊布，硅族单位自动成链；
  敌人只能从廊口涌入（正面决战地形）。
- **本关新决策课**：打后排（术士出现）/ 破光环 / 硅族机制（晶能/晶壁/共振）。

# 关 8 · 大城外围（帝国合流 · 多段防线）

- **场景**：终于看到帝国大城的轮廓——但城门外是魔族主力，正规军正在城头苦战；
  你们要从外围打进去合流。
- **撤退类型**：可撤——正规军接应，撤=退回城郊重整（不丢命，但大城压力更大）。
- **玩法变体**：**多段防线**——地图分段（前哨→中段→城门），逐段失守后撤守下一段；
  考资源分配（每段留多少兵）。
- **本关新决策课**：多段防线调度 / 资源全局分配 / 组合压力（不考新怪，考组合）。
- **敌人**：所有已见角色位组合（无新怪，考"读编制"）。

# 关 9 · 大城决战（终局 · 抉择结局）

- **场景**：大城。魔族主力（含恶魔领主）兵临城下。帝国正规军+你带了一路的队伍+各族盟友，
  全在这道城墙上。这是终点——或者，你还能选择再退一次。
- **撤退类型**：**决战特例**——死守大城=赢结局；主动再撤=放弃大城=开放式结局（非失败，是选择）。
- **玩法变体**：Boss 关——多阶段 Boss + 阶段召唤 + 城防分段崩溃表现。
- **本关新决策课**：Boss 阶段战（爆发窗口/控制链/阶段切换）。

- **对话与 flag（结局分叉点）**：
  - 守成后依据全战役 flag 出结局：满编+全结盟=`光荣入城`；残兵=`代价入城`；
    魔族内幕 flag 满=暗线真结局（停战/看清双方都是难民）；第5族线=隐藏结局。
  - 城头最后对话（若玩家选了再撤）：帝国皇帝/守将：
    A「城在人在」→ 死守（进结局结算）
    B「留得青山」→ **主动放弃大城**，带最后的人继续往更深处撤 → 开放式结局（中继，续作口）
- **失败与重试**：死守失败=全灭 → 重打；减员永久；大城若因你撤而沦陷（开放式结局）不算失败，
  算玩家选择的结局之一。
