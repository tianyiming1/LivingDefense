# 波次设计文档 (WAVE DESIGN v1.0)

> 状态：基于 S1-S3 四族实施，12 波验收通过；见 core_loop.md 与 BALANCE_MODEL.md
> 每波设计均来源于 RACES.md 四族决策轴 + BALANCE_MODEL 数值基准

## 核心原则

1. **教学递进**：每波至少引入 1 个新决策点，不堆砌无信息量难度（不只是“血量翻倍”）
2. **种族区分**：第 N 波四族玩家做的事两两不同（见 RACES.md §“玩家首 3 波在做什么”）
3. **决策密度**：每 1-2 分钟 1 个主要决策点（放置/技能/调位）
4. **难度=能力+新决策**：波次难度 = 玩家当下可用能力 + 本波新可学习的决策
