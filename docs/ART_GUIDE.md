# 美术风格指南 v1.0（可用/可检查版本）
> 状态：美术线规格（Owner：美术总监；R8 风险缓解项：颜色+剪影先行）
> 适用范围：TowerDefenseProto 全部视觉（当前全为脚本 draw_* 绘制，无外部资产）

## 0. 定位与预算
- 风格路线：**几何剪影 + 高对比色板**（2D 俯视，几何形体表意）
- 预算纪律（R8）：先定"颜色+剪影"语言，再生资产；现阶段零外部资产，全部 draw_* 实现
- 检查纪律：任何"好看/酷"的形容词不入验收清单；验收只认颜色值/形状/尺寸/时机

## 1. 六条可检查规则
1. **种族即色板**：每个种族由固定主色识别（见 §2），单位身体主色=所属种族色
2. **剪影表意**：每种单位有几何形状签名（人=方/矩、龙=尖三角、硅=六边/菱形、菌=圆伞）
3. **段/级可视**：升级、进化、技能状态必须肉眼可见（星点/光环/亮圈），不允许只改数字
4. **反馈有语义**：受击闪白、减速冰圈、攻速加速环、死亡消失——每个反馈对应一个明确游戏事件
5. **敌我区分**：敌方只用"敌色板"（锈红系），与四族色板不可混淆
6. **血条统一**：宽度/位置/颜色统一（己方金、敌方绿），唯一差异是长度

- 敌色板：锈红 #BF4A2F（Grunt）/ 冰蓝 #3A8FC6（Runner）/ 暗紫灰 #6E5A73（Tank）——与四族主色全部错开
