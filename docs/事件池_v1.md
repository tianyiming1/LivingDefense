## 0. 设计冻结（实现前必读）

### 0.1 定位

| 项 | 冻结 |
| --- | --- |
| 形态 | 局内**随时遭遇**（波中 / 波间均可抽签）；非开放世界探索、非固定每 N 波弹菜单 |
| 骨架 | 仍是 **经营 + TD + 全程部署**；事件 = RPG 调味，禁止变成「整局靠抽事件」 |
| 同屏 | **最多 1 个进行中事件**；结束后进全局冷却 |
| 可读 | 触发必有 HUD 状态句 +（WP-FX1）音效/轻闪；禁止静默改数值 |
| 可归因 | 玩家输/漏必须能说清「哪条事件 + 我哪次抉择」；禁止纯 RNG 致死无反馈 |
| 数据驱动 | 加行不加核；常量进 `Config`（建议前缀 `EVT_` / `WEATHER_`） |

### 0.2 全局调度建议（总线共用，非单事件）

| 常量建议 | 建议初值 | 含义 |
| --- | --- | --- |
| `EVT_GLOBAL_COOLDOWN_SEC` | 28.0 | 任一事件结束后全局冷却 |
| `EVT_ROLL_INTERVAL_SEC` | 18.0 | 冷却结束后每 N 秒尝试抽签（波中/波间共用） |
| `EVT_ROLL_CHANCE` | 0.35 | 单次抽中概率 |
| `EVT_MAX_ACTIVE` | 1 | 同屏进行中上限 |
| `EVT_MIN_WAVE` | 2 | 第 1 波禁随机（教学窗） |
| `EVT_BAN_WAVE_12_LAST_SEC` | 8.0 | 第 12 波末段禁新开高压危机（防不可归因闷杀） |
| `EVT_WEIGHT_SCALE_BY_PRESSURE` | true | 漏怪/低命时略降危机权重、略升机缘（复玩钩子，非保送） |

**权重口径**：下文「权重」为相对整数，总线归一化后抽样；同 `id` 达一局上限后权重视为 0。

### 0.3 分类覆盖（本池 ≥6 类）

天气 · 机缘 · 挖宝 · 危机 · 战场变异 · 抉择 —— 下列 **14** 条完整规格均属此六类。

## 1. 事件规格（14 条）

### EVT-WTH-01 · 霖雨滞敌

| 字段 | 内容 |
| --- | --- |
| **id** | `EVT-WTH-01` |
| **类别** | 天气 |
| **触发条件** | `wave_index ∈ [2, 11]`；当前无进行中事件；全局冷却结束；抽签命中；天气层当前非 `STORM`/`LIGHTNING`（可与晴转雨） |
| **持续时间** | `WEATHER_RAIN_DURATION_SEC` = **22.0**；结束后回 `CLEAR` |
| **对玩家的决策** | （1）是否趁减速窗口**补近战拦截 / 卖弱换远程**；（2）人族是否趁窗口**补农进站**（怪慢 = 经营窗）；（3）要不要提前点开下一波（雨内开波更安全，但雨可能在波中结束） |
| **数值效果** | 敌移速 × `WEATHER_RAIN_ENEMY_SPEED_MULT`（**0.82**）；友军远程射程 × `WEATHER_RAIN_RANGE_MULT`（**0.92**，湿雾轻微）；表现绑已有 `WeatherType.RAIN` |
| **成功归因** | 「雨里补了拦截，跑者没漏」/「雨窗把农补满再硬开波」 |
| **失败归因** | 「指望雨一直拖，雨停后跑者冲穿」/「雨里远程射程变短，我还把火枪往后撤」 |
| **权重建议** | 14（中高；早期教学友好） |
| **一局上限** | **2** |
