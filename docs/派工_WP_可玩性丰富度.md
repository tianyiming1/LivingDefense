# 《活体防线》派工 — 可玩性 / 丰富度 / 长留（严禁应付）

- **日期**：2026-09-03
- **制作人裁决**：随机事件只是支柱之一；目标是**一局有料、多局不腻、系统可长滚**
- **质量门禁（任一不过 = 返工，不算交付）**
  1. **好玩**：玩家能说出本局 ≥3 次「有意义抉择」（不是纯看戏）
  2. **可玩**：S1–S4 Autoplay 仍 ACCEPT；无崩溃；新人能打完一局
  3. **丰富**：事件池分类 ≥6，首包落地样例 ≥6（每类至少 1）；另有经营/地图/成长至少再动 1 条
  4. **能一直玩**：有复玩钩子（事件权重+地图差+经济压力）；禁止「做完三个事件就宣称完成」
