# 核心循环文档 (CORE LOOP v1.0)

## 1. 30秒说清的玩家核心体验

一句话：玩家在 30 分钟内，通过不断“部署单位卡位拦怪 → 观察战斗 → 触发主动技能 → 管理经济重铺”，在 12 波怪流中存活并消灭所有敌人，体验四个种族各异的博弈手感。

## 2. 完整流程分步描述（可复现步骤）

### Phase A：准备阶段（每波开始时）
1. **查看当前钱数**：main.money ≥ 当前选单位总造价
2. **打开建造界面**：HUD 显示可选单位（种族专属）
3. **放置单位**：
   - 点选单位 ID → 鼠标变成 ghost（preview）
   - 悬停走廊格子：Vector2 坐标需满足：距离走廊中心 ≥ 46px、屏幕内、互距 ≥ 50px
   - 满足条件则点击放置；不满足则弹出“钱不够/越界/重叠”提示
4. **完成布防**：点击“开始波次”，进入 WAVING 状态


### Phase B：战斗阶段（每波进行中）
1. **怪物自动进攻**：
   - 怪物沿预设路径前进（S0_mid→S2_mid→S3_mid→S4_mid）
   - 最近的单位自动攻击（双向：单位攻击怪，怪攻击单位）
   - 单位死亡 → 永久损失 + 可重购/重孵
2. **技能释放**（基于 SKILL_WAVES = [1, 3, 5, 7, 9, 11]）：
   - 主动技能仅在对应波次可释放
   - Rally Fire（人族）：8s 全军攻速 +50%
   - carpet_fever（菌族）：3s 菌毯伤害 ×3
   - dragon_fire（龙族）：直线穿透燃烧 3s
3. **波次计时**：spawn_timer 控制每秒刷怪数量
4. **经济计算**：每击杀 1 怪 → Config.KILL_REWARD 金钱

### Phase C：结算阶段（每波结束）
1. **波次结算**：
   - 所有怪物死亡或突破防线
   - 检查 main.state：
     - 胜利：state == WIN 且 lives > 0
     - 失败：lives ≤ 0 或 波次 > 12
2. **经济结算**：
   - money += kill_reward × monster_count + wave_bonus
   - wave_bonus = 40 + 6 × wave_index
3. **进入下一波**：自动返回布防阶段，或游戏结束

### Phase D：12 波全程（验收检查点）
| 波次 | 主要机制首次引入 | 玩家决策焦点 |
|------|-----|-----|
| 1 | 基础布防规则 | 首次放置，学习距离/边界检查 |
| 2 | 第一技能 CD 窗口 | 确认技能可释放时机 |
| 3 | 新单位类型出现 | 评估种族特化方向 |
| 4 | 菌毯蔓延开启 | 菌族：菌毯首次铺设位置 |
| 5 | 龙族孵化位解锁 | 龙族：是否攒位升级 |
| 6 | Rally Fire CD 达成 | 人族：火力齐射时机 |
| 7 | 传染链机制激活 | 菌族：感染链首次传播 |
| 8 | 护盾机制首次出现 | 龙族：护盾阈值触发 |
| 9 | 进化树第 2 段 | 人族：进阶单位可用 |
| 10 | BOSS 登场 | 所有种族对 BOSS 手感验证 |
| 11 | 主动技能全CD恢复 | 全族：技能循环闭环 |
| 12 | 终局 / 胜负判定 | 12 波通关 → ACCEPT / 漏怪 → REJECT |


## 3. 核心循环图解（文本版）

`
[开始] → [分配资金] → [放置单位(验证规则)] → [开始波次]
     ↓
[怪物前进 + 自动攻击] → [玩家技能判断] → [单位死亡/漏怪检查]
     ↓
[波次结束 + 经济结算] → [返回布防] → [循环递增波次]
     ↓
[第 12 波结算] → [WIN: 主动结算 / FAIL: 返工/砍范围]
`

## 4. 行为描述可验证性

每个阶段的判定依据均来源于代码/配置：
- **布放规则**：_test_placement_rules() 中的 SPOTS 字典 + 边界检查
- **经济结算**：I(w) = ΣKill × KILL_REWARD + (40 + 6w)，见 BALANCE_MODEL §3
- **技能时机**：SKILL_WAVES 列表 + skill1_last_wave CD 追踪
- **波次难度**：HP(w) = HP0 × 1.10^(w-1)，见 BALANCE_MODEL §2
